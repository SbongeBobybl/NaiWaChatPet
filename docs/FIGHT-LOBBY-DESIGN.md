# 联机大厅界面

版本：2026.10.21-fighting.9。浅色原生 Win32 大厅，沿用现有奶蛙插画，不改骨骼动作。

基准 900×560，按显示器工作区和 DPI 缩放。顶部横向导航为联机、设置、高级；右侧保留单机挑战和桌宠入口。附近房间、当前房间左右并列，列表按行显示，不再使用左侧导航栏、大圆角卡片、渐变和阴影。正常状态只占底部一行；设置自动保存时留空，改键后只显示简短“已保存”。

暖白底 #FAF9F4，深色字 #30382F，次级文字 #626B5F，金色主操作 #E9B537，选中行 #F6E8BE。使用 Microsoft YaHei UI，原生 Tab/Enter/Esc 导航和焦点反馈。按钮悬停只变颜色，位置固定。保持房间码、创建/加入/准备、改键和音量滑块的原功能。

页面、按钮和房间行先离屏合成再提交；无常驻装饰动画计时器。纯色矩形直接填充，减少无用的圆角距离计算。DIB 写入、复用和释放前刷新 GDI。DPI 变化延后处理，相同缩放不重复创建画布。

大厅窗口类在进程内复用；原生句柄分别映射到对应窗口，子控件不再依赖全局“活动大厅”。最小化窗口重新打开时恢复；窗口已失效则释放旧资源并重建。系统销毁窗口时清除缓存。类注册、窗口和控件创建失败时记录具体原因，并显示简短错误。

previews/lobby-room-list.png 是实际原生窗口单次捕获，A7C204/E2941B 是视觉检查样例；原生流程检查另建真实 TCP 房间。未使用生成式 UI 样图。

终局页在原“当前房间”位置显示“本局结果”和胜利/失败/平局，双方席位显示各自结果，主要操作为再来一局。以服务端最终快照为依据，持续保留，不依赖短暂 KO 事件；进入下一局即清除。首次显示立即绘制，原生验证在正常消息分发后只捕获一次。
