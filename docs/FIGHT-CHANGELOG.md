# 奶蛙格斗更新记录

## 联机结算、平衡与操作衔接 `2026.10.21-fighting.9`

- 联机终局从服务器持久快照显示胜利/失败/平局，覆盖 KO、超时、错过短暂事件及重新进入大厅；双方按各自视角显示，下一局清除结果。
- 血量统一降至旧版 80%，标准双方 80，挑战对手 48/64/80/112；时限 60→120 秒。按用户确认，damageScale=1.25 保留原单次普攻/飞扇/翻滚/灼烧伤害，旧数值配置兼容默认值。
- 战斗专用移动加速、刹停和反向响应更快；桌宠原控制参数不变。合法普通攻击后段及技能收招可接移动、跳跃或下一动作，有效攻击帧不被提前跳过。
- 收招短输入缓存保留普攻和跳跃；眩晕将结束时可预输入，恢复后才执行，修复控制器浮点硬直残留导致解控末帧吞键。技能结束事件只触发一次，不遗留翻滚碰撞或重复扣蓝。
- 联机预测与服务端共享加减速规则，使用真实速度、斜向归一化、动作锁和相同边界处理，减少起停及边界纠正。
- 慢帧后以保留输入空档的方式补帧，避免再空等一个刷新周期；同机短实跑活动展示约 43→54 FPS，仍保留队列与重入保护。
- 保留浅色大厅、原始骨骼、六次受击保护及无冷却 L；只做本轮针对性检查与实际运行采样。

## 浅色紧凑大厅与打开恢复 `2026.10.21-fighting.8`

- 大厅改为暖白底、深色文字、金色操作。顶部横向导航，房间列表和双方席位并列；撤掉大圆角卡片、阴影和整块自动保存提示，简化文字。
- 窗口类在进程内复用，句柄映射到各自大厅，避免重复注册失败时静默退出以及消息路由到旧面板。
- 打开已最小化大厅会恢复；缓存句柄失效时重新创建。系统销毁窗口也会清理缓存、原生画布和字体。
- 窗口、控件及画布创建失败有诊断记录和可见错误，可再次尝试。
- 保留按需绘制、离屏合成和 DPI 防重入；纯色矩形使用直接填充。
- 完成针对性原生大厅检查和新 EXE 三轮游戏/大厅切换；未做全项目回归或新增跨机联网验收。

## 大厅稳定性与精简界面 `2026.10.21-fighting.7`

- 停止大厅 30Hz 装饰性整页重绘，移除卡片进场位移、按钮扫光与文字抬升。仅数据、焦点、鼠标状态变化时更新。
- 页面、按钮及房间行使用各自的离屏画布，背景和文字合成后一次提交，修复按钮文字间歇消失。
- 在 DIB 写入、复用及销毁前完成 GDI 操作，恢复绘制上下文，校验画布创建失败。
- DPI 通知延后处理；禁止建窗/绘制/重排期间嵌套重排，相同缩放比例保留原字体及画布。
- 保留当前暖金色设计，精简说明、状态和按钮文案，移除重复奶蛙插画；提高次级文字对比度。
- 四项针对性原生 UI 检查通过，新 EXE 实际打开大厅并运行三轮；未扩大到全项目回归。


## 联机持续运行与菜单整理 `2026.10.21-fighting.6`

- 战斗刷新标记保持到整帧绘制结束；防止慢帧不断投递刷新消息挤占输入，并阻止 Win32 嵌套消息重复进入战斗帧。
- 所有五类技能特效统一预热，程序绘制分辨率独立于 DPI；保留原显示尺寸，预热帧约 17 MiB，缩放缓存最多 8 MiB。双方共享有界技能帧缓存，满后只淘汰最久未用的一帧。
- 每帧最多处理已有的网络更新；写入恢复后合并过期移动输入，保留一次性按键事件。结束、等待及断线阶段同样限制快照至 20Hz。
- 过期一秒的表现事件不再反复传输。比赛序号随快照同步，错过整个倒计时后也能接收新一局较小的 tick，不会继续等待旧局进度。
- “游戏”菜单保留单机挑战、联机大厅、游戏设置和武器；对局中显示结束入口。操控、召唤、表演、苍蝇、散步和专注移到“互动内容 → 桌宠玩法”。选择正在进行的单机挑战会继续对局，选择单机入口可从联机切换。
- 保留现有 LAN 自动建房/发现、技能比例、六次受击保护与无冷却 L；未修改用户骨骼、聊天或个人设置。


## 第五版：精细大厅与一技能比例修复 `2026.10.21-fighting.5`

- 重新制作原生联机大厅：薄荷绿与暖白配色，圆角卡片、清晰房间列表、双方席位、准备与倒计时状态，保留键盘焦点及原生控件语义。
- 设置独立成页：音量/特效滑块、原地按键重绑定、恢复默认按键与自动保存。高级服务器连接独立成页。
- 修复控件创建期间提前收到输入通知，使部分按钮错误保留可点击状态的问题；禁用重复建房/准备，空列表不能直接加入，隐藏无效复制/离开操作。
- 新增房间码复制、双击房间加入、同一界面的改键与明确错误反馈；显示按当前网卡环境工作的联机权限入口。
- 一技能按普通角色基准放大 12%，保持落脚线，玩家和对手共用校准；扇子起点使用相同变换，旧 combat.json 自动兼容。修复缺失骨骼时左向扇子备用起点的镜像错误。
- 单机打开大厅/设置自动暂停；进入战斗停止隐藏大厅刷新。窗口按工作区和 DPI 适配，字体、滑块、列表行高同步调整。
- 运行三个针对性检查，并实际启动新 EXE 约 12 秒、进出战斗三次；没有重跑全项目长回归。原始技能资源逐字节校验，未修改关键帧。

## 第四版：热点房间发现修复 `2026.10.20-fighting.4`

- 修复单一通配网卡广播对热点/VPN 多网卡环境不可靠的问题；现在逐网卡绑定源地址广播。
- 新增 TCP 28761 热点发现通道与自动有界探测，广播失效时仍有备用路径，无需手动 IP 或 CMD。
- 保留随机查询校验、局域网限制、连接/包长度/频率限制，增加并发上限与搜索取消；进入战斗即停止后台搜索。
- 新增 Windows“联机权限”页面入口，修正只提示允许专用网络的误导，明确热点可能属于公用网络；不自动改系统防火墙。
- 房间列表和失败提示区分广播未响应与可能设备隔离；降低自动探测频率。
- 提供单 EXE 更新包，双方可覆盖原目录客户端；协议仍为 v2，但双方应一起更新才能使用备用发现。
- 只做三项必要的发现/加入/目标覆盖检查，不以本机实网卡检查冒充双电脑热点验收。

## 第三版：局域网便捷联机与脱身保护 `2026.10.20-fighting.3`

- 创建房间自动启动进程内权威服务器；大厅自动发现同一局域网的房间，选择即可加入，房间码可选。普通流程无需 CMD 或 IP。
- 手动地址与连接检测移到高级连接，保留独立公网部署能力。准备倒计时结束自动进入战斗，结束后打开大厅。
- 增加有长度、来源、随机查询标识和速率限制的 UDP 房间发现，监听与游戏 TCP 端口在离开房间时回收；不广播用户名和聊天等个人信息。
- 连续受 6 次直接攻击后获得 30 tick（0.5 秒）保护，并解除当前硬直。受击链在 66 tick（1.1 秒）没有直接受击后重置；灼烧不计数。
- L 冷却为 0，动作中再次点按可衔接下一次闪避；保留单次动作时长和无敌窗口，禁止长按无限重启。
- 协议升级 v2，双方及独立服务器使用本版。仅做本次改动的必要验证，未宣称跨实体机器或公网实测成功。

## 初版

本轮基于本地实际 `Source/NaiWaChatPet` 修改，没有用 GitHub 文件覆盖本地工程。GitHub 主分支审计点为 `f15fed688f95e2ed48d9c2330a8f268a69c4d82b`；已读取要求核对的九个战斗/骨骼/客户端文件。开发分支为 `codex/fighting-20261020`，修改前源码备份位于本地报告目录。

- 引入无 Win32 依赖的 60Hz 战斗核心，统一生命、蓝量、百分比伤害、技能、灼烧、眩晕、强化、闪避和胜负。
- 保留三连击、移动、跳跃、武器倍率与掉落、连续挑战；新模式关闭旧固定伤害路径，双方共用规则。
- 加入飞扇独立弹体与扫掠碰撞、翻滚根位移与一次命中、强化治疗与持久层数、闪避无敌窗口和输入缓冲。
- 无修改接入用户 Spine 4.2.43 骨骼、原始曲线和事件；加入手部锚点、镜像、打断、姿态过渡及可替换资源加载接口。
- 加入蓝条、技能可用/冷却、状态标记、伤害数字、分层程序爆炸、冲击波、残影反馈及程序合成音效。
- 加入简单/普通/困难战术 AI，使用与真人相同的资源、动作锁与技能验证；支持弹体预判、闪避、距离控制和近期习惯调整。
- 加入真实 TCP 服务器权威房间、双人准备、倒计时、快照、位置预测/插值、重连、再来一局、限流、版本校验与 TLS。
- 加入原生游戏大厅与设置、按键重绑定、聊天/焦点输入保护；修复退出时对手窗口的清理顺序。
- 根据真实运行 CPU 采样优化显示尺寸光栅化、等尺寸重采样、绘图缓冲复用、HUD 重复生成和特效缓存；高精度计时消息与固定逻辑步长分离。
- 构建 Windows 客户端、Windows/Linux 服务端，增加构建、打包、隐私检查和新 EXE 双客户端测试脚本。

未修改 DeepSeek、聊天和情绪业务逻辑、桌面整理业务逻辑及用户骨骼关键帧。游戏存档仅添加可选 `game` 字段；旧武器、胜场和挑战记录保持同一 JSON 字段，旧数据可继续读取。

未完成与未验证项目见测试报告：尤其是 L 正式动画、人工 GUI、不同实体机器和公网部署。未推送或发布到 GitHub。
