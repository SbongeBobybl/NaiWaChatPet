# 奶蛙格斗 · 局域网便捷版

构建：`2026.10.21-fighting.9`，Windows x64。先退出旧奶蛙，运行本目录的 NaiWaChatPet.exe；保留 animations、skill-assets、Organizer 等配套目录。

## 本轮更新

联机结束后，大厅和 HUD 明确显示胜利、失败或平局，结果保留到下一局；错过 KO 特效也能看到服务器最终结果。超时血量比例相同时判平局。

血量降为原来的 80%：标准对战双方 80，单机对手同步降低 20%；时限从 60 秒延长到 120 秒。按用户确认，普攻、飞扇、翻滚和灼烧保留原来每击伤害，标准对战分别为 1、5、7、每跳 0.2。combat.json 增加 damageScale=1.25；旧配置缺少此字段时自动继承。强化仍恢复当前最大血量的 5%（80 血时恢复 4）。

移动、刹停和反向使用战斗专用响应参数；桌宠散步不变。技能在效果和有效攻击窗口结束后，可从收招衔接移动、普攻、跳跃或下一技能。普通攻击/跳跃提供 150ms 收招输入缓冲；眩晕最后 100ms 的按键可排队到恢复后执行，不能提前解除眩晕。L 无冷却及六次受击保护继续保留。

联机位置预测同步使用实际加减速、斜向速度、动作锁定和边界规则，减少纠正造成的跳动。浅色紧凑大厅及原有技能骨骼保持不变。

双方退出旧奶蛙，用本版 EXE 覆盖原目录并重新创建房间；保留资源和配置。独立服务器也需更新，房主使用旧版服务时仍会沿用旧血量和时间。实际检查范围见 docs/FIGHT-TEST-REPORT.md。

## 局域网联机：直接在游戏里操作

1. 两台电脑连接同一局域网，使用本版客户端。
2. 房主：右键奶蛙 → 游戏 → 联机大厅 → 创建房间。
3. 好友：打开联机大厅，房间列表会自动发现房间；选择它并点加入房间。没立刻显示时点刷新。
4. 双方点准备，倒计时后自动进入战斗。

不需要单独启动服务端、不需要 CMD、不需要输入 IP。也可以输入好友的 6 位房间码，程序会在局域网查找。首次出现 Windows 网络访问提示时，请允许奶蛙访问专用网络。

房主离开游戏或退出奶蛙，房间随之关闭。对局结束可双方点再来一局。Esc 打开大厅；正常聊天和桌宠功能仍保留。

## 本次手感调整

- 连续受到 6 次直接攻击后，获得 0.5 秒保护并立即解除当前硬直，期间可以移动、攻击和闪避；有蓝色保护圈及 GUARD 提示。第 6 次攻击仍正常结算伤害。
- 连续受击链在 1.1 秒未再次被直接命中后重置；灼烧不计入六次受击，也不清除已有灼烧。
- L 完全取消技能冷却，连续点按可衔接下一次闪避。单次动作仍约 0.30 秒，无敌约 0.18 秒；长按不会无限重启。
- 保留上一版的战斗期间主动陪伴隔离、开局无聊天气泡、翻滚中段放大 30%。用户骨骼原始文件未修改；L 正式骨骼仍待提供。

J 普攻，U 飞扇，I 翻滚，O 强化，L 闪避；WASD/方向键移动，Shift 跑，K/Space 跳。大厅设置可重新绑定主按键、AI 难度、音量和特效。

公网/云服务器连接放在高级连接中；NaiWaFightServer.exe 是可选的独立部署工具，局域网对战无需运行它。更多信息见 docs/FIGHT-NETWORK.md。

用户已反馈两台设备可局域网联机；本轮验证仅覆盖大厅原生流程及本机 TCP 准备；用户热点长时间复测及公网仍需另验。本包不包含个人配置、API Key 或聊天记录。源码构建可运行 scripts/BUILD_FIGHT.ps1（Go 1.27）；独立整理模块保持原发行版内容。
