# 奶蛙格斗联机说明

本版 `2026.10.21-fighting.9`，协议仍为 v2。两位玩家使用同一新版客户端，主界面默认局域网房间列表；高级连接保留给手动服务器、公网及 TLS。

本轮标准对战为双方 80 血、120 秒。每击伤害保持旧值；终局快照中的 Winner 持续保留，-1 在结束阶段表示平局。双方及房主/独立服务器请一起更新后重新建房。

## 同一局域网直接玩

房主打开联机大厅并点击创建房间。客户端自动在进程内启动权威服务器，自动分配空闲游戏端口，发布房间代码；无需外部程序或地址设置。

好友打开联机大厅，程序自动寻找同一网络上的等待房间。在左侧房间列表选择房间，点击加入房间（双击也可加入）；也可以输入 6 位房间代码后加入。当前房间卡片显示双方是否加入/准备。双方准备后倒计时，自动收起大厅并把控制交回奶蛙。比赛结束可再来一局，Esc 可随时打开大厅。

关闭房间或退出房主进程时自动停止房间服务、发现响应和连接。普通游戏模式下不常驻后台房间服务器。断线期间尝试重连 30 秒，房主退出后需重新建房。

## 热点搜不到房间：本版修复与使用步骤

双方必须更新到 `2026.10.21-fighting.9`。退出旧程序，将新版 EXE 覆盖到原来的奶蛙目录可保留原路径和资源。房主创建房间后，好友打开大厅，等待约 3 秒或点击刷新；选中房间加入，双方准备。仍然不需要 CMD、查 IP 或手动启动服务器。

旧版只通过一个未绑定具体网卡的 UDP 套接字发送广播。热点过滤广播、多网卡/VPN 改变路由时，可能收不到回应。本机回环发现成功不能证明两台电脑可互通。此外，旧提示只提“专用网络”，而 Windows 经常把热点识别为“公用网络”。本次没有拿到两台设备的抓包，不能断言用户此次失败只由某一个原因造成。

本版逐个网卡绑定源地址发送广播，并增加独立 TCP 发现通道。即使 UDP 广播完全不可用，也会自动探测同一小型子网的房间。手机常见的 /24 或更小网段会完整覆盖；更大网段只探测本机所在 /24 和子网首个主机地址，避免扫描整个大型网络。多网卡任务交替安排，最多 1024 个目标、48 个并发连接，单次搜索约 2.8 秒，自动搜索间隔 8 秒。进入战斗、关闭大厅或离开游戏会取消搜索并释放套接字。

若仍没有房间，房主点大厅右下角“网络权限”，程序只打开 Windows 的“允许应用通过防火墙”页面。找到或添加**当前版本的 NaiWaChatPet.exe**，由你选择允许当前网络。若使用受信任的手机热点，而 Windows 把它识别为“公用”，只勾选“专用”不会生效。程序不会替你更改规则、关闭防火墙、修改网络类别或开放路由器公网端口。安全软件或单位管理策略也可能另外阻止设备连接。

如果已允许当前网络仍无法互通，请检查热点/路由器是否启用了“AP 隔离”“客户端隔离”“禁止设备互访”，或改用允许设备互访的普通 Wi-Fi。这类隔离会连 TCP 一起阻止，应用无法绕过。VPN 若接管局域网流量，也需在 VPN 中允许局域网访问。

## 发现通道与数据范围

发现监听 UDP **28761** 与 TCP **28761**，实际游戏使用房主自动分配的 TCP 端口。UDP 和 TCP 可以使用相同端口号。房主退出时这三类监听与连接一起关闭，不常驻独立后台服务。

发现仅传协议、随机实例标识、房间码、人数及游戏端口，不传用户名、聊天、桌面信息或 API Key。查询带随机标识，执行本地子网来源检查、长度限制、超时、并发和响应限流。连接地址来自实际回应来源，不由数据包指定任意外部主机。

## 高级连接与独立公网部署

点左侧“高级连接”后可输入 host:port 或 tls://host:port。此模式才需要单独部署 NaiWaFightServer.exe。Windows 启动示例：

    NaiWaFightServer.exe -listen :28760

Linux amd64：

    chmod +x ./naiwa-fight-server-linux-amd64
    ./naiwa-fight-server-linux-amd64 -listen :28760

公网推荐添加 -tls-cert fullchain.pem -tls-key privkey.pem，客户端填 tls://域名:28760。证书私钥由部署者管理，不在发行包内。云安全组和防火墙需允许所部署 TCP 端口。公网仍需独立实测。

战斗继续使用 60Hz 服务器权威逻辑、约 20Hz 快照、输入序号、有限预测/插值、房间隔离和重连令牌。客户端不能提交伤害或 HP。两端及独立服务端需使用本版协议 v2，旧版不混用。

## 本轮验证范围

本轮只修改大厅绘制、DPI 和文字。LAN 发现、权威战斗、跨局比赛序号、重连和技能规则保留。原生大厅检查使用真实 TCP 双客户端创建、加入及准备；本轮未重复跨机器、热点长时间对战或公网验收。
