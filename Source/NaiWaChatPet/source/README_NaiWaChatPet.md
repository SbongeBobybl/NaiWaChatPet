# NaiWaChatPet 13.4.0

Windows x64 桌面奶蛙，Go 1.27.2+，原生 Win32/GDI，不依赖浏览器进行日常聊天。

本版本包含：紧凑的金色输入面板、奶油色回复气泡、整体按压回弹按钮、动作子菜单、奶蛙图标及桌面快捷方式；每条消息独立判断开心/惊讶/疑惑/害羞/伤心/生气，再发起正常流式聊天。情绪期间屏蔽悬停打拳，保留完整入场、主体和退场动画。惊讶动画的左眼从原视频像素恢复。

13.4.0 新增：`play` 包把按键变成桌面上的走、跑、跳和三连击（`Controller`，纯逻辑、可测试），并含打苍蝇与散步逻辑；`rig` 包用骨骼驱动的蒙皮网格弯曲原有渲染帧来画这些动作（`Stand`、`Stance`、`Figure` 三套骨架，静止时与原画一致）；`emotion/catalog.go` 是全部表情的唯一来源。宿主中的 `play_windows.go` 负责按键、热键、菜单和用点击穿透的小分层窗口绘制阴影、苍蝇、命中效果与分数，`sprites.go` 为这些小图的纯绘制代码。

主动陪伴可设置最短 30 秒，由当前大模型结合最近聊天及最近主动发言生成 2–4 句内容。输入、阅读、正在回复、免打扰时段及频率上限都会延后触发。出厂默认关闭，在设置中启用后，同一版本保存启用状态。

配置与记忆保存在 `%APPDATA%\NaiWaChatPet\versions\13.4.0`。API Key、最近成功聊天和最近主动发言由 Windows DPAPI 当前用户加密。新版本使用独立目录，不读取旧版个人资料。发布包仅包含允许的程序/源码/动画/图标/说明，禁止带入运行配置、日志或接收的文件。

构建：在源码目录运行 `go build -trimpath -ldflags "-s -w -H windowsgui" -o ..\ReadyToRun\NaiWaChatPet.exe ./cmd/codexpet`。将包内 `animations` 放在 EXE 同级。`app_windows_amd64.syso` 已包含原奶蛙图标；图标生成器在 `cmd/make-icon`，资源生成脚本见源码包根目录。

输入框 Enter 发送，Shift+Enter 换行，Esc 收起，Tab 导航按钮。长回复支持滚动及展开。F10 打开独立开发情绪调试窗口，主气泡不显示 JSON、标签、置信度或调度信息。

回退：情绪模型超时、非法 JSON、非法标签、低置信度会返回待机，正常聊天仍独立执行。主聊天本身断网时显示自然错误提示，可重试。恢复出厂菜单会在清除本版本资料前确认；其他版本和接收的原文件保留。

历史 README 保留用于源码追溯；当前行为以本文件和发布根目录 CHANGELOG.md 为准。旧的八标签情绪评估不适用于本版本的六类自动情绪策略。本次未使用个人 API Key 重新测量模型分类准确率，不把 confidence 或程序检查通过率当成模型准确率。
