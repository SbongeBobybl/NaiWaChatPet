模型连接

Key 与最近聊天使用 Windows 当前用户加密后保存在本地，不进入日志。更换服务地址需重新填写 Key，并清除旧服务的聊天记忆。

关闭流式可用于兼容性诊断。截断或中断会明确提示，不作为完整回复写入历史。

回答风格

你在问题中明确要求详细回答时，会优先满足问题，长度偏好不会强制截断。

固定应用规则、人设和自定义偏好分层管理。奶蛙只根据你提供的内容回答，不假装看过未授权的屏幕。

主动陪伴

启用后结合最近对话，由当前模型生成 2–4 句自然陪伴内容，并记住近期发言来减少重复。无需打开屏幕观察；输入或正在阅读时会延后。定时请求按模型 API 计费，同版本会保存启用状态；新版出厂默认关闭。

屏幕感知

显示器中存在排除应用时，本次截图会拒绝执行。自动附图会显示在桌面输入框，发送前可选择“仅文字”。图片只发给当前模型服务，按图片和文本计费；只在内存临时保留。

情绪与动作

26 种自动表情，启动后显示就绪情况

每条消息先判断奶蛙的回应情绪，再自然说话。情绪动作播放期间，鼠标悬停不会触发打拳抢占；不适合表现情绪时保持待机。右键奶蛙 → 表情 可以直接播放任意一种。

导入新的动画素材

在源码目录运行 go run ./cmd/import-emotions 导入表情 GIF，go run ./cmd/import-scene 导入在纯色背景前拍摄的视频片段（例如搬箱子）。导入后的动画放在 EXE 旁的 animations 中即可。

玩法手册

右键奶蛙 → 一键整理桌面：奶蛙抱起箱子，把 PDF、表格、文档、图片、快捷方式等分门别类放进文件夹。文件夹和正在使用的文件不动，随时可以“撤销上次整理”。

  • 单击奶蛙打开输入框，Enter 发送，Shift+Enter 换行，Esc 收起；双击捧腹大笑，拖动移动位置。
  • Ctrl+Alt+G 操控奶蛙：←↑→↓ 或 WASD 移动，按住 Shift 跑，J 出掌三连击，K 跳（空中可再跳一次），数字键做表情。
  • 操控时会有苍蝇飞来，出掌或跳起来用嘴接；Ctrl+Alt+H 让奶蛙跑到鼠标旁。
  • 右键还有：表演一段、自己散步、专注 25 分钟、大小、截图预览、暂停和退出。
  • 文件喂食保留原安全处理；含 NTFS 备用数据流的文件会保留来源。
