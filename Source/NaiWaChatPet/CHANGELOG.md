# NaiWaChatPet 13.4.0 — 键盘操控、骨骼动画与 26 种表情

- 键盘操控：方向键或 WASD 走动，按住 Shift 跑，J 出掌（连按为三连击，第三下重掌并前冲更远），K 或空格跳（按得越久跳得越高，空中可再跳一次）。只在奶蛙拥有键盘焦点时读取按键，不安装全局键盘钩子。Ctrl+Alt+G 开关操控，Ctrl+Alt+H 召唤到鼠标旁；快捷键被占用时菜单照常可用。会在屏幕边缘和任务栏前停下并沿边滑动，可跨显示器；朝右走时整幅画面镜像，脚下阴影随跳跃缩小。
- 骨骼动画：新增 `source/rig`，用骨骼驱动的蒙皮网格直接弯曲原有渲染帧，含站立、拳架和任意定格姿势三套骨架。不拆分、不重画肢体，各层取自同一帧并在软遮罩下重叠，静止姿势与原画逐通道误差不超过 2/255，起步没有跳变；走路时待机呼吸照常播放。原“打拳”片段实为定格拳架，出掌动作由骨骼收臂、推掌和身体前冲生成。
- 未沿用 13.3 的分件骨骼方案：那种做法要把肢体重新生成为独立图层，关节处会断开，轮廓和面部也与原角色不一致。
- 表情：模型可选表情由 6 种扩展为 26 种，另有 7 种奶蛙自用姿势；轻微开心改为微笑，强烈时仍播放完整捧腹大笑。`source/emotion/catalog.go` 统一生成分类提示词、协议校验、回答语气和菜单，旧的本地陪伴标签 comforting、thinking 分别映射为拥抱、思索。
- 新姿势由 `cmd/import-emotions` 从提供的 GIF 导入：只取定格姿势（中间帧是带白边和重影的光流插帧），去除白色地面与白边，双边滤波平滑 256 色色带，颜色匹配原渲染，并按双脚位置对齐到待机姿势的大小和地面（原 GIF 各帧之间最多错位 32 像素）。切换时奶蛙先轻轻下蹲再换姿势，定格期间由骨骼做点头、摇头、摇摆、颤抖等细微动作。
- 玩法与实用：操控时打苍蝇（出掌命中或跳起用嘴接，显示得分与连击，保存最好成绩），没事时自己散步，召唤到鼠标旁，专注 25 分钟，表演一段；启动时打招呼，等待模型回复时托腮思索，被快速来回拖动后晕乎，深夜久未互动时犯困。数字键 1–9、0 在操控中直接做表情。
- 修复：锁屏或 UAC 提示期间系统拒绝读取鼠标位置时，奶蛙不再自行退出。旧版诊断日志中这一错误导致过 4 次退出。
- 性能：缩放对合成画布走直接像素路径，输出与原算法逐字节一致，默认大小下单帧缩放由约 12 ms 降至约 1 ms。移动时身体最多每秒重绘 30 次，窗口位置每帧更新。
- 新增测试覆盖骨骼还原原画、出掌手掌不越出画布、控制器的走跑跳与连击与屏幕边缘滑动、苍蝇与散步、表情目录一致性、微笑分流和精灵图预乘。`go test ./...` 全部通过。
- 本机实际运行（离线 demo 模式）验证了走、跑、跳、二段跳、连击、朝向翻转、脚下阴影、苍蝇和定格表情的呈现。本次未用真实 API Key 测量 26 类表情的模型判断准确率；置信度不是准确率。
- 按既定要求，本版本从独立的 13.4.0 出厂目录开始，需要重新填写一次 API Key。
