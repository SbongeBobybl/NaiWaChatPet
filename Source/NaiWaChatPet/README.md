# NaiWaChatPet

奶蛙桌面 AI 陪伴宠物 · 当前版本 **13.4.0**

NaiWaChatPet 是一款面向 Windows 的桌面宠物。奶蛙可以自然聊天、表现情绪，能用键盘操控着在桌面上走、跑、跳和出掌，并在开启主动陪伴后结合最近的对话主动说话。日常聊天直接在桌面完成，浏览器用于配置连接和陪伴设置。

## 功能特点

- **原生桌面宠物**：使用 Go、Win32 和 GDI，支持拖动、调整大小和奶蛙桌面快捷方式。
- **自然聊天**：接入 DeepSeek，支持流式回复和温柔、憨厚的奶蛙人格。
- **键盘操控**：方向键或 WASD 在桌面上自由走动，按住 Shift 跑，J 出掌（连按三下是三连击），K 跳，空中还能再跳一次。会在屏幕边缘和任务栏前停下，可以跨显示器。
- **骨骼动画**：走、跑、跳和出掌由骨骼驱动的蒙皮网格实时生成，直接弯曲原有的渲染帧，不拆分、不重画肢体，所以站立时与原画逐像素一致，起步没有跳变。
- **玩法与实用**：操控时打苍蝇（出掌或跳起来用嘴接，记录最好成绩）、没事时自己散步、一键召唤到鼠标旁、专注 25 分钟、表演一段。
- **情绪动画**：26 种模型可选表情（原有 6 种视频表情加 20 种新姿势），另有 7 种奶蛙自己用的姿势，以及完整捧腹大笑；轻微的开心改为微笑。
- **独立情绪控制**：先分析情绪，再生成回复；通过优先级、情绪惯性、冷却和衰减调度动画。
- **主动陪伴**：最短间隔 30 秒，结合最近对话生成陪伴内容，支持免打扰时段和发言上限。
- **本地记忆**：保存 API 配置、近期对话和陪伴记忆，支持恢复出厂设置。
- **奶蛙主题界面**：金色输入框和回复气泡，支持多行输入、长回复展开及滚动阅读。

## 快速开始

1. 将运行包完整解压到可写入的文件夹，不要在压缩包内直接运行。
2. 保持 `NaiWaChatPet.exe` 与 `animations` 文件夹同级，双击 EXE 启动。
3. 程序正常启动后会创建或更新桌面的 **NaiWaChatPet** 奶蛙图标快捷方式。
4. 右键奶蛙，选择 **设置 / DeepSeek 连接…**，填写自己的 API Key，选择模型并保存。可使用页面中的连接测试。
5. 单击奶蛙打开输入框，输入消息后按 Enter 或点击发送。

运行环境：Windows 10 / 11，64 位。运行包无需安装 Go 或 Python；AI 聊天需要联网和可用的模型 API。未配置 API 时，仍可使用右键菜单中的动作。

运行目录主要内容：

```text
NaiWaChatPet.exe       主程序
animations/           动画资源，请保持完整
NaiWaChatPet.ico       奶蛙图标
使用说明.md            操作说明
CHANGELOG.md           版本记录
```

## 桌面操作

| 操作 | 用途 |
| --- | --- |
| 单击奶蛙 | 打开奶蛙下方的聊天输入框（操控模式中只是把键盘交还给奶蛙） |
| 拖动奶蛙 | 调整桌面位置 |
| Enter | 发送消息 |
| Shift + Enter | 输入换行 |
| Esc | 收起输入框 |
| Tab / Shift + Tab | 在输入框和按钮之间切换焦点 |
| 右键 → 动作 | 播放待机、捧腹大笑、害羞、惊讶、伤心、生气、疑惑等动作 |
| 右键 → 表情 | 播放 27 种新姿势表情中的任意一种 |
| 右键 → 操控模式 / Ctrl+Alt+G | 开关键盘操控；奶蛙有键盘焦点时直接按方向键也会进入 |
| 方向键 / WASD | 走动，按住 Shift 跑 |
| J | 出掌，连按打出三连击，第三下是重掌 |
| K 或空格 | 跳，按得越久跳得越高，空中可以再跳一次 |
| 数字键 1–9、0 | 打招呼、欢呼、庆祝、得意、拒绝、拥抱、思索、不悦、害怕、晕乎 |
| Esc / Enter | 退出操控 / 退出操控并打开聊天 |
| 右键 → 召唤到鼠标旁 / Ctrl+Alt+H | 奶蛙跑到鼠标旁边打招呼 |
| 右键 → 表演一段 | 奶蛙自己把走、跑、跳、连击演示一遍 |
| 右键 → 玩法与实用 | 打苍蝇开关、自己散步开关、专注 25 分钟 |
| 右键 → 大小 | 调整奶蛙尺寸或恢复默认大小 |
| 右键 → 暂停观察与提醒 | 暂停屏幕观察和主动提醒 |
| 右键 → 退出 | 关闭程序 |

操控模式只在奶蛙拥有键盘焦点时读取按键，不安装全局键盘钩子，因此不会影响其他程序的输入；点击别的窗口后奶蛙脚下的金色圈会变暗，再点一下奶蛙即可继续。两个全局快捷键如果已被其他程序占用，菜单里照常可用，只是不显示快捷键。

发送、仅文字和预览截图按钮的整个圆角区域都可点击。长回复可展开阅读并滚动；上下小箭头用于滚动，仅在内容超出显示区域时出现。

## 情绪与动画

每条消息先由模型结合当前内容、最近对话和奶蛙人格判断适合表现的情绪，再独立生成自然回复。奶蛙不会机械复制用户的情绪。

模型可选 26 种表情：原有的 **开心、惊讶、疑惑、害羞、伤心、生气**，以及新加入的 **喜爱、得意、欢呼、庆祝、打招呼、感谢、赞同、拒绝、思索、好奇、害怕、担心、哭泣、委屈、失望、尴尬、困倦、不悦、放松、拥抱**。每种表情的适用场景和回答语气集中写在 `source/emotion/catalog.go`，提示词、校验、菜单和回答指导都从这里生成。不适合表现情绪或情绪分析失败时回到待机，聊天请求仍会继续。开心强烈时播放完整捧腹大笑，轻微时微笑。

另外 7 种姿势由奶蛙自己使用：微笑、兴奋、专注、无聊、傲娇、晕乎、震住。启动时打招呼，等待模型回复时托腮思索，被快速来回拖动后晕乎，深夜久未互动时犯困，专注计时开始和结束时分别专注、庆祝。

新姿势由导入工具从提供的 GIF 中取出定格姿势，去掉白色地面和白边、平滑 256 色造成的色带、匹配原有渲染的颜色，再按脚的位置对齐到待机姿势的大小和地面。切换时奶蛙先轻轻下蹲再换成新姿势，定格期间由骨骼做点头、摇头、摇摆、颤抖等细微动作。

情绪动作播放期间，鼠标悬停的打拳动作不会抢占。连续消息会结合当前状态、冷却时间和重复触发规则调度动作，随后自然返回待机。

想直接查看生气动画，可选择 **右键 → 动作 → 生气**；连接模型后也可以说“奶蛙，表演生气一下”。如果只说“我很生气”，奶蛙可能选择安慰你。

按 F10 可打开独立情绪调试面板，查看模型判断、动画调度和实际播放。内部情绪 JSON、标签和置信度不会进入日常聊天气泡。

## 主动陪伴

在设置中开启 **大模型主动陪伴**，可将间隔设为最短 **30 秒**。奶蛙会结合最近对话和近期陪伴内容生成多句自然回应，避免一直重复同一句话。

30 秒是最早允许触发的间隔。正在输入、回复、阅读，处于免打扰时段，或达到每小时发言上限时，主动陪伴会延后。默认免打扰时段为 23:00 至次日 08:00，可在设置中调整。

新版本默认关闭主动陪伴和屏幕观察；同一版本保存后的设置会在重启时恢复。主动陪伴会调用所配置的模型 API，可能产生服务商费用。

## API、记忆与隐私

同一版本只需保存一次 API Key，正常重启后会恢复。程序保留有限的近期成功对话及主动陪伴内容作为记忆，并不是无限保存所有历史。

本版本的数据目录：

```text
%APPDATA%\NaiWaChatPet\versions\13.4.0
```

- `companion-preferences.json`：个性和陪伴等设置。
- `companion-memory.dpapi`：API Key、近期对话和陪伴记忆，使用 Windows 当前用户的 DPAPI 加密保存。
- `play.json`：打苍蝇开关、散步开关和最好成绩。

每个新版本使用独立配置目录，以出厂状态启动，不自动导入旧版本 API、记忆或个性设置。之后在该版本保存的数据会继续保留。

AI 聊天会将消息和必要的近期上下文发送到所配置的模型服务。屏幕观察默认关闭，截图相关功能需要授权，支持先预览再发送。

**恢复出厂设置：** 在右键菜单或设置页面选择恢复出厂，确认后清除当前版本的 API、记忆、个性设置和已知诊断日志。其他版本的数据目录和接收的用户文件会保留。

**拖入文件：** 文件接收功能可能将文件转移到 EXE 同级的 `ReceivedFiles`，成功转移后原位置的文件可能被删除。该目录可能包含私人原文件，恢复出厂不会删除它；请先用非重要文件了解此功能。

## 常见问题

- **无法聊天：** 检查网络、API Key、服务地址、模型名称及服务商余额，在设置中进行连接测试。
- **动画不显示：** 确认已完整解压，`animations` 与 EXE 同级且资源没有缺失。
- **主动陪伴没有立即说话：** 检查是否开启、是否配置 API、免打扰时段、发言上限，以及输入框或回复框是否仍打开。
- **升级后需要重新配置：** 新版本使用独立出厂配置；在该版本保存一次后，正常重启会保留。

## 从源码构建

项目主要目录：

```text
source/               Go 源码和本地设置页面
animations/           动画帧与清单
icons/                奶蛙图标资源
ReadyToRun/           构建输出
BUILD_WINDOWS.ps1     Windows 构建脚本
CHANGELOG.md          版本记录
```

安装 **Go 1.27.2 或更新版本**，在包含 `BUILD_WINDOWS.ps1` 的项目根目录运行：

```powershell
.\BUILD_WINDOWS.ps1
```

脚本会构建 `ReadyToRun\NaiWaChatPet.exe` 并复制动画。手动构建可在 `source` 目录运行：

```powershell
go build -trimpath -ldflags "-s -w -H windowsgui" -o ..\ReadyToRun\NaiWaChatPet.exe ./cmd/codexpet
```

手动构建后也需将完整 `animations` 文件夹放到 EXE 同级。

动画相关工具（在 `source` 目录运行）：

- `go run ./cmd/rig-preview -out rig.png`：把走、跑、跳、出掌和定格动作渲染成对照图，并检查静止姿势与原画是否一致。调整骨骼、遮罩或动作曲线后先看这张图。
- `go run ./cmd/import-emotions -gifs <GIF 目录> -sheet poses.png`：重新导入表情 GIF，输出到 `animations/` 并生成审阅图。
- 测试运行可加 `-no-shortcut`（不改动桌面快捷方式）、`-demo`（离线，不访问模型）和 `-play-demo`（启动后自动表演一段）。更多实现说明见 [源码说明](source/README_NaiWaChatPet.md)，版本变化见 [CHANGELOG.md](CHANGELOG.md)。
