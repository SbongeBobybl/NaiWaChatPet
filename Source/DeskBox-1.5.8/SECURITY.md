# Security Policy

**English** | [中文](#中文)

---

## English

### Supported versions

Only the latest published release receives security fixes. Please check [Releases](https://github.com/Tianyu199509/DeskBox/releases) before reporting.

### Reporting a vulnerability

Please do **not** open a public issue for security problems. Instead:

1. Use GitHub's private vulnerability reporting: [Report a vulnerability](https://github.com/Tianyu199509/DeskBox/security/advisories/new).
2. Or email: **1047078635@qq.com** with `[DeskBox security]` in the subject.

Include what you found, how it could affect users, and reproduction steps if available. You will receive an acknowledgment within 7 days. Fixes ship in the next regular release unless the issue is critical.

### Scope notes

DeskBox is a local desktop application: it does not operate servers or process other users' data. Reports about the application itself, its installer, updater, or the optional WebDAV cloud-backup client flow are all in scope.

## 中文

### 支持版本

仅最新发布版本接收安全修复，报告前请先查看 [Releases](https://github.com/Tianyu199509/DeskBox/releases)。

### 如何报告漏洞

请**不要**用公开 Issue 报告安全问题，而是：

1. 使用 GitHub 私有漏洞报告：[Report a vulnerability](https://github.com/Tianyu199509/DeskBox/security/advisories/new)。
2. 或发送邮件至 **1047078635@qq.com**，标题注明 `[DeskBox security]`。

请说明发现的问题、可能对用户造成的影响，以及可复现的步骤（如有）。我们会在 7 天内确认收到；非严重问题随常规版本发布修复。

### 范围说明

DeskBox 是本地桌面应用，不运营服务器、不处理其他用户的数据。应用本体、安装器、更新器以及可选的 WebDAV 云备份客户端链路都在受理范围内。
