# DeskBox 全局唤醒和跨应用拖放怎么用？在微信和浏览器里直接拿文件

文件整理好以后，最耗心力的步骤往往还在后面。你在微信里准备发送一个附件，文件明明已经分好类，还是得先最小化窗口，回到桌面或资源管理器，找到目录，再拖回聊天框。

DeskBox 想缩短的就是这段路。它让文件格子平时留在桌面层级，需要时再临时来到当前窗口附近。文件从格子拖到微信、浏览器上传区域或资源管理器以后，格子可以再收回去。

这项能力解决的是每天会重复很多次的一个动作。

> [动图占位，微信聊天窗口保持打开。按 F7 唤起 DeskBox，从文件格子拖出一个文件到发送区域]

## 全局唤醒让格子不必一直压在前面

DeskBox 的格子可以常驻桌面，也可以在需要时临时显示。默认全局快捷键是 F7。

在浏览器、微信、编辑器或其他程序处于前台时，按一次 F7，DeskBox 会显示或唤起格子。找到目标文件后可以直接拖放、打开或编辑。再次按下快捷键，可以按当前行为隐藏全部格子，回到原来的工作画面。

这条入口特别适合两个时刻。

- 当前程序已经打开，只差把一个文件拖进去。
- 文件格子平时收成胶囊，不想为了找一份文件先整理整张桌面。

如果 F7 和游戏、输入法、IDE、截图工具或笔记本功能键冲突，进入设置中的快捷与交互全局快捷键区域重新录制即可。录制时按 Esc 可以取消。搜索格子还可以配置独立搜索快捷键，避免与显示或隐藏全部格子的快捷键互相抢占。

## 托盘适合不想记快捷键的时候

系统托盘中的 DeskBox 图标是另一条稳定入口。右键托盘图标可以显示或隐藏全部组件，也能快速打开随记、创建文件格子、进入设置、打开收纳目录、整理桌面、配置开机启动或退出。

左键托盘图标适合临时唤起或提升现有格子。快捷键遇到冲突、刚开始还没形成肌肉记忆，或者正在远程连接电脑时，托盘入口更容易找到。

> [图片占位，展示 DeskBox 托盘菜单。标出显示全部、创建文件格子、整理桌面、设置和退出]

## 从格子拖到微信、浏览器和资源管理器

文件格子使用 Windows 文件拖放。发送时按下面的顺序操作就可以。

1. 在当前软件里按 F7，或点击托盘唤起 DeskBox。
2. 找到文件所在格子。格子处于胶囊状态时，点击或悬停标题区域展开。
3. 选中文件，按住鼠标左键开始拖动。
4. 把文件拖到微信聊天窗口、浏览器上传区域、资源管理器目录或其他接收文件的软件。
5. 松开鼠标，观察目标软件的接收提示。

文件无需先导出成临时包。微信会按自己的逻辑进入发送流程，浏览器会开始上传，资源管理器会按 Windows 文件操作规则处理。DeskBox 提供的是一个更近的文件来源。

格子组中的文件格子同样支持这条路径。当前构建也继续处理了微信等非 WinUI 应用的原生拖放兼容，让常见的 OLE 和 WM_DROPFILES 文件载荷能正确到达格子。

## 反过来，聊天附件和下载内容也能拖进来

文件流动不只发生在发送时。从资源管理器、微信和浏览器拖内容到文件格子，能把刚到电脑的资料直接送进“待处理”或项目目录。

收纳格子通常按复制处理，来源文件仍会保留。需要时可在文件格子设置中改成移动。映射文件夹直接使用目标真实目录的 Windows 文件操作语义。

浏览器里的远程图片或文件链接需要按界面提示确认导入。微信等聊天软件有时提供临时文件对象，重要附件更建议使用复制保存，或者先保存到本地，再放入收纳格子。

拖到待办或随记时，文件会作为任务或记录的附件保存。拖向收起的胶囊，目标格子会临时展开，让你在松手前确认要添加到哪里。

## 胶囊、格子组和全局唤醒怎样配合

胶囊处于收起状态，文件格子仍会保留名称和数量。需要拿文件时，点击胶囊、在指定区域悬停，或者先通过 F7 唤起所有格子，都能回到展开状态。

一个项目有文件、待办和随记时，可以把它们放入格子组。你可以在同一位置切换到文件成员，再把资料直接拖到聊天窗口。切换完成后，组的位置、大小、锁定状态和收起状态会保持下来，不必重新找三个窗口。

这套组合适合把桌面保持得干净一些，同时不把“拿一个文件”变成完整的窗口切换流程。

## 拖放失效时，先检查权限级别

Windows 会阻止不同权限级别窗口之间的部分拖放操作。DeskBox 以管理员身份运行，微信、浏览器或资源管理器以普通权限运行时，跨应用拖放可能失败。

日常使用不需要管理员权限。确认 DeskBox 和接收文件的软件处于相近权限级别，再重新尝试。文件仍在下载、聊天软件尚未完成接收、目标目录没有写入权限时，也会导致拖放失败或被拒绝。

如果快捷键无法触发，先检查是否被其他应用占用，再换一个组合键。修改快捷键后完全退出并重新启动 DeskBox，可以排除旧注册仍被系统占用的情况。

## 常见问题

### 按 F7 会不会把所有内容一直置顶

F7 用于显示、隐藏或临时唤起格子。格子的长期窗口层级仍由各自设置决定，完成操作后可以再次隐藏或收起。

### 可以从 DeskBox 直接拖文件给微信吗

可以。微信当前窗口接受 Windows 文件拖放时，从展开的文件格子拖出真实文件即可。

### 为什么拖不进微信或浏览器

先检查两个程序的权限级别是否一致，再确认文件已完整下载、目标应用正处于可接收状态。部分应用和网页只接受特定区域或特定格式的拖放。

### 胶囊收起后能接收文件吗

可以。把文件拖向胶囊时，DeskBox 会临时展开目标格子。完成后它会回到原来的收起状态。
