# DeskBox 音乐格子：控制当前播放器、显示封面和进度

听歌时最常见的打断，不是换歌本身，而是为了暂停、调音量或查看歌名，反复切回播放器窗口。

DeskBox 音乐格子使用 Windows 媒体会话读取当前播放器状态，在桌面上提供一组轻量控制。它不是音乐库，也不会接管播放器的本地歌单。

## 一句话理解音乐格子

音乐格子是当前系统媒体会话的桌面控制面板：显示曲名、歌手和封面，并提供播放、暂停、上一首、下一首、进度、播放模式和音量操作。

## 第一次使用

1. 进入 `设置 > 功能格子`，启用音乐。
2. 打开任意支持 Windows 媒体会话的播放器并开始播放。
3. 从托盘或功能格子设置显示音乐格子。
4. 根据格子尺寸选择自动、封面、控制或唱片布局。

如果当前没有媒体会话，音乐格子会显示“没有正在播放”，而不是生成虚假的曲目信息。

## 音乐格子能控制什么？

常用控制包括：

- 播放和暂停。
- 上一首和下一首。
- 拖动播放进度。
- 调整音乐音量或系统音量，具体取决于当前会话能力。
- 正常播放、循环播放和随机播放。
- 查看当前来源、曲名、歌手和专辑封面。

不同播放器对 Windows 媒体会话的支持程度不同，因此个别控制项可能不可用。

## 五种显示模式

音乐设置中的显示模式包括：

- **自动**：根据格子大小选择合适布局。
- **封面模式**：突出专辑封面和当前曲目信息。
- **控制模式**：突出播放控制与进度。
- **唱片（竖排）**：以竖向唱片视觉展示。
- **唱片（横排）**：适合宽一些的格子。

小格子更适合控制模式或自动模式；希望音乐成为桌面氛围的一部分时，可以使用封面或唱片布局。

## 封面氛围背景和悬停动效

开启“封面氛围背景”后，DeskBox 会从当前封面提取颜色，生成轻量的半透明背景，让格子和当前专辑形成视觉联系。

“封面悬停动效”会在鼠标移入封面时提供轻微缩放和跟随移动。它可以在设置中关闭，适合希望桌面始终保持安静的用户。

格子隐藏、收起或空闲时，封面跑马灯和唱片旋转等高频视觉动效会降低或停止，避免音乐格子在后台持续消耗不必要的资源。

## 和胶囊模式一起使用

音乐格子可以收起为一个更紧凑的胶囊，保留当前歌曲、播放状态或封面提示。组合排列时，可以把音乐放在屏幕右侧，与天气、待办组成信息栏。

如果不希望音乐内容占据主工作区，推荐：

1. 使用自动显示模式。
2. 将音乐格子缩小到适合控制的尺寸。
3. 开启胶囊模式。
4. 将它和天气放入独立的右侧组合排列。

## 常见问题

### 为什么音乐格子没有内容？

确认播放器正在播放或暂停了一首歌曲，并且它支持 Windows 媒体会话。不同播放器的元数据和控制能力不同。

### 音乐格子会保存我的音乐文件吗？

不会。它读取当前系统媒体会话，不建立音乐文件库，也不复制音频文件。

### 为什么切歌时歌名会短暂变化？

播放器切歌时可能先发布部分媒体信息，DeskBox 会等待完整信息后更新，减少曲名和歌手闪烁。

### 可以把音乐格子和其他格子合并吗？

当前格子组需要可持续显示的标准或紧凑标题栏。音乐格子的具体标题样式和可合并状态以当前工作树界面提示为准。
