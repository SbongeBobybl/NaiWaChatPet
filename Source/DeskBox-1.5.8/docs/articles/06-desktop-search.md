# DeskBox 桌面搜索：一次找到文件、应用、待办和随记

文件明明存在，但你不记得它在“项目素材”“下载”还是聊天附件目录；一条随记也明明写过，却想不起当时放在哪个标签。搜索的价值不是让你记住更多路径，而是把“我记得一点点”变成可以执行的结果。

## 一句话理解 DeskBox 搜索

DeskBox 搜索把应用、文件、文件夹、待办和随记放进同一个搜索入口，并为结果提供打开、复制路径、预览、保存到随记和附加到待办等下一步动作。

> [图片占位：搜索弹窗展示“全部、应用、文件、文件夹、DeskBox、随记、待办”等结果分类]

## 怎么打开搜索？

你可以：

- 点击搜索格子。
- 使用搜索快捷键直接打开搜索弹窗。
- 从托盘或其他 DeskBox 入口进入搜索。

搜索快捷键在 `设置 > 功能格子 > 搜索` 中单独配置。搜索弹窗会优先显示输入框，推荐应用、历史和索引结果可以在后台继续恢复。

## 搜索哪些内容？

根据设置启用的范围，搜索可以覆盖：

- 应用和开始菜单项目。
- 文件和文件夹。
- DeskBox 文件格子中的内容。
- 待办正文、日期和状态。
- 随记正文、链接和附件信息。
- 最近使用和最近搜索。

默认结果可以选择全部、应用、文件、文件夹或 DeskBox 内容等分类。结果还会按文档、图片、视频、音乐和压缩包等类型继续筛选。

## Windows 索引和本地扩展索引

DeskBox 可以组合不同搜索来源：

1. **Windows 系统索引**：搜索 Windows 已经索引的位置，启动成本较低。
2. **DeskBox 内容搜索**：查找待办、随记和格子内容。
3. **扩展本地索引**：后台扫描本机固定磁盘，覆盖范围更大，但可能增加磁盘、内存和首次扫描时间。

扩展索引可以在 `设置 > 功能格子 > 搜索` 中开关、暂停、继续或重建。搜索长期空闲后，较大的本地索引可以从内存卸载；再次唤起搜索时会开始恢复，不需要重新输入文字才能触发。

## 推荐、历史和收藏

没有输入关键词时，搜索可以显示：

- 推荐应用。
- 最近使用。
- 最近搜索。
- 收藏的搜索。

搜索历史默认是本地活动记录，可以单独关闭或清空。需要处理敏感内容时，关闭搜索历史并清理已有记录。

## 搜索结果不只是“打开”

常见结果操作包括：

- 打开文件、文件夹或应用。
- 打开所在位置。
- 复制路径。
- 重命名文件。
- 将文件移到回收站。
- 使用 QuickLook 预览。
- 将结果保存到随记。
- 将文件附加到待办。
- 复制或剪切文件。

例如搜索到客户合同后，可以直接把它附加到“本周交付”待办；搜索到参考资料后，可以保存到随记，避免再回头找路径。

## 结果筛选和键盘操作

搜索结果可以使用分类标签和类型筛选。结果较多时，用关键词限定文件名，再用类型筛选图片、文档或视频。

搜索框中可以用方向键浏览结果，按 Enter 执行打开；选中文件后按 Space，在已运行 QuickLook 时可以预览。搜索结果也支持多选和批量打开、删除等操作，批量操作前先检查选择范围。

## 搜索和隐私

搜索活动、索引和 DeskBox 内容默认保存在本机。扩展索引会读取你选择范围内的本地文件元数据，因此应该根据磁盘空间、性能和隐私需求选择是否开启。

搜索不是云端全文检索，也不会因为开启 DeskBox 就自动上传整个磁盘。

## 一个“找到即行动”的流程

1. 按搜索快捷键打开弹窗。
2. 输入项目名、客户名或文件类型关键词。
3. 用结果分类缩小范围。
4. 直接打开、预览或复制路径。
5. 如果文件还要继续跟进，附加到待办；如果只是临时参考，保存到随记。

## 常见问题

### 为什么搜索不到刚创建的文件？

Windows 索引和扩展本地索引都可能需要时间；确认搜索范围已开启，并查看设置中的索引状态。也可以尝试重建索引。

### 搜索会搜索待办和随记吗？

会。需要在搜索范围中启用 DeskBox 内容，并且对应的待办或随记功能已开启。

### 搜索快捷键和 F7 是一样的吗？

不是。F7 默认用于显示、隐藏或唤起全部格子；搜索可以使用独立快捷键。

### QuickLook 是 DeskBox 自带的吗？

不是。DeskBox 以被动兼容方式调用已经安装并运行的 QuickLook；没有 QuickLook 时，搜索和文件格子仍可正常工作，只是无法使用空格预览。
