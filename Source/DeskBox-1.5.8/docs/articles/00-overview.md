# DeskBox 是什么？用桌面整理、文件格子和小组件把 Windows 桌面用顺

电脑刚开机时，桌面往往很干净。用上几天，浏览器下载、微信附件、截图、导出文件和临时文档就会一点点冒出来。每个图标当时都有理由留下来，过几天再看，桌面已经变成一块谁都不敢轻易碰的地方。

文件要用时，麻烦才会冒出来。你记得它来自某次聊天，也记得大概是上周下载的，却还得先回桌面，再打开资源管理器，一层层找目录。要发给微信里的同事，还要把刚才的路径再走一遍。

DeskBox 从这件小事开始做。它保留 Windows 原来的桌面和文件夹，在桌面上放一组能实际操作的格子。文件有更近的入口，待办和随记能靠近正在处理的资料，天气和音乐也能留在视线边缘。需要时把格子唤起，做完再收回去。

> [图片占位，展示一个日常 DeskBox 桌面。画面包含文件格子、待办、随记、天气和收起的胶囊]

## Windows 桌面为什么总会重新变乱

桌面天然适合接住临时内容，却没有提供一套顺手的后续动作。文件落到这里以后，人们通常会立刻找最终目录，或者先放着，或者继续创建更多文件夹。

前一种会打断正在做的事。第二种把桌面变成一堆没有名字的待办。第三种会让目录越来越细，下一次放文件时又要重新判断它该去哪里。

DeskBox 给了第四个选择。先把内容放进用途明确的格子，等工作走到合适的地方再归档。桌面上原本散开的图标，开始有了可见的入口和下一步。

文件格子是这件事的中心。桌面整理负责处理已经积累的文件，自动整理负责接住之后稳定出现的新文件。两者都围绕真实路径工作，避免界面上看着整齐，资源管理器里却找不到文件。

## 文件格子让文件有个近一点的入口

文件格子可以理解成摆在桌面上的文件夹工作面。它既能创建一个新的收纳位置，也能映射你早已在用的项目目录。

收纳格子适合接收新内容。比如把微信附件、待处理截图、当天的导出文件先放进一个叫“待处理”的格子。格子背后有真实文件夹，拖入时可以按设置复制或移动。

映射文件夹适合已有结构的人。项目目录、代码仓库、素材库和常用模板无需搬家，选中原目录后，DeskBox 会在桌面上显示这批真实文件。你在格子里打开、重命名、删除或移动文件，资源管理器中的目录也会同步变化。

| 眼前的情况 | 更合适的做法 |
| --- | --- |
| 文件刚来到电脑，还没想好长期位置 | 创建收纳格子 |
| 项目目录已经整理好，只想更快打开 | 映射已有文件夹 |
| 希望来源文件继续保留 | 拖入收纳格子时选择复制 |
| 希望文件离开原来的临时位置 | 拖入收纳格子时选择移动 |

> [动图占位，从微信拖入一个附件到“待处理”格子，再把项目目录映射到桌面]

格子里可以用图标或列表查看内容，按名称、类型、大小和日期排序，也可以批量选择、复制、剪切、粘贴、重命名和删除。自动叠放能把图片、文档、压缩包等内容在同一格子里分组展示，真实目录不会因此多出一层子文件夹。

详细说明请看 [文件格子与桌面收纳](01-file-widgets.md)。

## 桌面整理处理已经堆起来的文件

很多软件把“一键整理”做成一个很轻的按钮。用户关心的事却很重，文件会被移到哪里，下载到一半的内容会不会被碰到，整理错了能不能回来。

DeskBox 的桌面整理会先扫描，再把移动计划摆出来。你能看到准备处理的文件、对应的分类、接收它的格子或文件夹，以及最终真实路径。某一类文件不想动，可以在确认前留下来或换一个目标。确认以后才会执行真实移动。

这条流程会多出一次确认，也会在移动前把路径摆清楚。你知道文件要去哪里，才更愿意让工具替你做重复的动作。

整理完成后会留下本次批次的结果和可用的撤销入口。文件夹、隐藏或系统项目、下载中的文件、临时文件、云盘占位文件、权限不足的项目以及超过限制的大文件，会被谨慎地保留在桌面。

详细说明请看 [桌面一键整理与自动整理](02-desktop-organization.md)。

## 自动整理解决的是明天又乱的问题

一键整理处理过去，自动整理处理之后的变化。

它默认关闭。启用时，DeskBox 会先记录当前桌面状态，已有文件继续留在原处。之后才出现的新文件，只有匹配规则并通过稳定性检查，才会进入目标格子。文件刚出现时常常还在下载、解压或导出，DeskBox 会等待它停止变化。状态拿不准时，文件留在原地。

先为“图片素材”建立一条规则，观察一段时间，再增加文档或交付包，通常比一次设满所有扩展名更稳。自动整理的价值在于减少重复动作，也要让人始终知道它会把什么送到哪里。

## 小组件补上 Windows 桌面一直缺的那一部分

文件被安顿下来以后，桌面还有另一类东西值得留下来。它们不需要占一整个应用窗口，人却经常要在工作途中看一眼。

### 待办格子

待办适合放今天要做、等别人回复、需要带附件发出的事项。它可以带日期、提醒、重复、颜色和附件。把一份文件附到任务上，下一次打开待办时，文件和动作会一起出现。

### 随记格子

随记负责接住临时文字、链接、图片、文件和最近剪贴板。它适合还不值得进入正式笔记系统的信息。常用内容可以固定，之后要找的时候也不用翻很长的聊天记录。

### 桌面搜索

搜索把文件、文件夹、应用、待办和随记放进同一个入口。只记得一点关键词时，可以先用搜索找到对象，再继续打开、复制路径、预览、保存到随记或附到待办。

### 天气和音乐

天气格子提供当前位置或指定城市的天气与预报。音乐格子读取 Windows 媒体会话，方便暂停、切歌、看封面和调节进度。这两种格子都适合放在桌面边缘，抬眼能看见，不必长期占住主工作区。

它们各自的使用方法在 [待办格子](03-todo-widget.md)、[随记格子](04-quick-capture.md)、[桌面搜索](06-desktop-search.md)、[天气格子](07-weather-widget.md) 和 [音乐格子](08-music-widget.md) 中有完整说明。

## 格子太多时，收起和合并比关闭更顺手

桌面工具常见的两难很直接。全部展开会挤占空间，全部关闭又会失去入口。

胶囊模式给每个格子留一个收起状态。文件、待办、随记、天气和音乐可以只保留图标、标题、数量或关键摘要。点击或悬停后再展开。把文件拖向胶囊时，它还可以临时展开，让你确认落点。待办和随记的摘要可以隐藏，屏幕共享或录屏时更从容。

一个项目常常同时有项目文件、待办和临时记录。格子组能把它们放进同一个桌面表面，通过标题栏的成员入口切换。文件不会合并到一个目录，待办和随记也不会混成一份数据。它只是让同一项目的几个入口共享位置和尺寸，减少找窗口的动作。

详细说明请看 [胶囊模式](09-capsule-mode.md) 与 [格子组](10-widget-groups.md)。

## 在微信和浏览器里，怎样快速把文件拿出来

整理好文件以后，发送文件仍然是一个高频动作。DeskBox 提供托盘入口和全局快捷键。默认按下 F7 可以唤起或隐藏格子，也可以在设置中换成更适合自己的组合键。

微信聊天窗口、浏览器上传框、资源管理器目录和其他接受 Windows 文件拖放的软件，都可以接收从文件格子拖出的真实文件。反过来，从资源管理器或聊天软件拖入内容时，收纳格子会按设置执行复制或移动。

这一段路径很短，却会反复出现。文件不再需要为了发送而先回到桌面或重新翻目录。

详细说明请看 [全局唤醒与跨应用拖放](05-global-wake-and-drag-drop.md)。

## DeskBox 会替换 Windows 桌面吗

不会。Windows 桌面、资源管理器和既有目录仍然照常使用。DeskBox 在它们之上提供文件入口、整理流程和信息格子。

收纳格子和映射格子背后都是普通 Windows 文件夹。你可以在资源管理器中继续访问它们。DeskBox 卸载或退出后，重要文件也不应该只依赖一个桌面工具，因此项目文件、版本控制、云盘和系统备份仍按原有习惯使用。

## 文件格子和映射文件夹有什么区别

收纳格子会创建或使用一个收纳位置，适合接住新的文件。映射文件夹连接已有目录，适合把常用项目摆到桌面。收纳格子中的拖入动作可能复制或移动文件，映射本身不会改变目录位置。

无论使用哪一种，格子里的重命名、删除和主动移动都可能影响真实文件。自动叠放只改展示方式，桌面整理和自动整理则会在条件满足后移动真实文件。

## DeskBox 需要账号或云同步吗

DeskBox 以本地数据为主，不要求注册账号。待办、随记、格子配置和相关数据保存在本机。天气、更新检查以及部分链接导入等功能会在使用时联网。

本地保存不等同于加密。胶囊中的隐私显示只负责收起状态下隐藏部分文字，不能替代磁盘加密、账号权限或独立备份。

## 第一次使用，建议从这四步开始

1. 创建一个名为“待处理”的收纳格子，用它接住新文件。
2. 映射一个正在进行的项目目录，确认不用搬动原有结构也能在桌面访问。
3. 打开桌面整理，先检查预览和目标路径，再处理积累的桌面文件。
4. 需要时再加一块待办或随记。等一个项目的文件、任务和记录开始同时出现，再考虑格子组和胶囊模式。

这套顺序不会要求你立刻换掉原来的工作方式。先让一个动作变顺，随后再决定哪些格子值得留下。
