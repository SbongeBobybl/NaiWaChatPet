# DeskBox 文件格子怎么用？把桌面文件收进手边，也保留真实路径

一个文件刚到电脑时，往往还没有确定归属。微信附件、浏览器下载、截图、客户发来的素材、软件刚导出的成品，都会先停在桌面。每次都立刻归档很费心，放着不管又会变成下一周的搜索任务。

文件格子给这批内容留了一个近一点的落点。它看起来像桌面上的一个小窗口，里面放的却是普通 Windows 文件和文件夹。你可以把它当成临时收件箱，也可以把已经整理好的项目目录直接摆到桌面。

这里要先看清一件事，格子里看到的文件有真实路径。拖入、重命名、移动和删除都要按真实文件操作来理解。知道这一点，后面的设置会清楚很多。

> [图片占位，左侧展示“待处理”收纳格子，右侧展示“当前项目”映射格子，并标出两者对应的真实路径]

## 先决定你要接住新文件，还是打开旧目录

DeskBox 提供两种文件格子。名称看着相近，解决的是两件不同的事。

### 收纳格子适合还没决定归档位置的文件

创建收纳格子后，DeskBox 会在收纳根目录下建立对应的真实文件夹。你可以把“待处理”“微信附件”“本周交付”“待确认素材”这类名字用在这里。文件拖入格子以后，会按设置复制或移动到这个目录。

它适合处理刚发生的动作。浏览器下完一份资料，不必先把项目目录翻出来，先丢进“待处理”。等需要处理时，再把它送进项目、附到待办，或者归档到正式位置。

### 映射文件夹适合已经在用的目录

项目目录、代码仓库、设计素材、OneDrive 工作目录和常用模板，很多人早已有自己的结构。映射文件夹会把这个真实目录显示成一个格子，目录本身不会被复制，也不会换位置。

这种用法的好处是路径不必重新学习。资源管理器和 DeskBox 展示的是同一批文件。你在格子里打开、重命名、删除或主动移动文件，真实目录会立刻变化。

| 你眼前的情况 | 选择 |
| --- | --- |
| 文件刚收到，先需要一个稳定落点 | 收纳格子 |
| 目录已经有清楚结构 | 映射文件夹 |
| 想保留文件原来的位置 | 拖入收纳格子时使用复制 |
| 想让文件离开桌面或下载目录 | 拖入收纳格子时使用移动 |
| 想把一个常用项目摆到桌面 | 映射文件夹 |

## 用两个格子开始，先把路径跑通

第一次不用摆满桌面。创建一个“待处理”收纳格子，再映射一个正在做的项目目录，就能看见文件格子的基本用法。

1. 在系统托盘中找到 DeskBox，创建一个文件格子。
2. 输入“待处理”之类的用途名称。
3. 拖入一张测试图片或一个测试文档。
4. 从格子标题菜单打开它在资源管理器中的位置，确认文件确实在这个目录。
5. 再选择映射文件夹，指定已有的项目目录。
6. 双击映射格子中的一个文件，确认它仍由 Windows 默认应用打开。

这两步做完，你已经拥有一个接收新内容的地方和一个回到项目的入口。后续添加格子，也更容易判断它该承担哪一种角色。

## 拖进格子时，复制和移动差在哪里

拖入收纳格子时，DeskBox 可以使用复制或移动。

复制会让来源位置继续保留原文件，收纳目录增加一份副本。刚开始使用时，复制更适合验证流程。重要附件、聊天软件提供的虚拟文件，以及还要留在原项目中的资料，也更适合用复制。

移动会把文件送进收纳目录，来源位置不再保留它。下载目录和桌面里的临时文件，处理完后常常更适合移动。

默认行为可在设置中的文件格子收纳与路径区域调整。开始拖动时也要看目标提示。跨磁盘、目标目录权限和来源程序的行为，都会影响 Windows 最终允许的操作。

映射文件夹直接对应一个真实目录，拖入时沿用该目录的 Windows 文件操作语义。它不会多保存一份 DeskBox 专用副本。

## 微信、浏览器和资源管理器里的文件怎样放进来

文件格子使用 Windows 原生拖放。常见的入口有这些。

- 从资源管理器拖入文件或文件夹。
- 从微信聊天窗口拖入附件。
- 从浏览器拖入已经下载到本地的文件。
- 从浏览器拖入可下载的图片或文件链接，按界面提示确认导入。

聊天软件和浏览器有时提供的是临时文件对象，拖放结束前才会变成可用文件。重要附件建议优先用复制，或者先保存到本地后再拖入。目标提示出现“不允许”时，先检查文件是否仍在下载、目标目录是否可写，以及当前程序的权限级别是否一致。

如果格子收在胶囊状态，悬停或点击后可以展开。全局快捷键和托盘也能把所有格子暂时唤起，方便从其他应用直接拖入。

## 从格子拖到微信，省掉一次找路径

发送文件时，文件格子的作用很直观。唤起 DeskBox，找到文件后按住鼠标，把它拖到微信聊天窗口、浏览器上传区域、资源管理器目录或其他支持文件拖放的软件。

文件没有经过“导出”这一步，因为它本来就是普通文件。接收方决定后续动作。微信通常进入发送流程，浏览器会开始上传，资源管理器按 Windows 规则复制或移动。

这条路径尤其适合常发的项目成果、报价单、图片和压缩包。文件格子离当前窗口更近，发送时不必从头翻一次文件夹。

## 格子里可以像操作普通文件夹一样做事

文件格子支持双击打开，支持 Ctrl 加点击、Shift 加点击和空白处框选。选中以后可以复制、剪切、粘贴、复制路径、重命名、删除到回收站，或者打开文件所在位置。

这些动作有实际后果。映射目录中的删除会删除真实文件，收纳格子使用移动时会改变文件原路径。批量移动、删除和重命名前，先看清选中的文件数量和目标位置。

图标视图更适合图片和视觉素材。列表视图更适合文档、安装包和需要看日期、大小、类型的目录。排序、文件名显示宽度、列表字段和图片只显示图标等选项，都只改变格子里的展示。

## 文件很多时，用叠放减少噪音

一个“当前项目”格子里有图片、文档、压缩包和导出文件时，全部平铺会让人先看到一堆图标。自动叠放可以按文件类型、日期或自定义扩展名规则分组显示，方便先缩小视线范围。

叠放没有移动文件，也不会创建新的子文件夹。它只改格子里的呈现方式。文件要改路径，仍由你主动执行移动、桌面整理或自动整理。

电脑中已经运行可用的 QuickLook 时，选中文件按空格可预览支持的格式。预览能力来自系统中可用的 QuickLook 处理器，不同格式的效果会有差异。

详细设置请看 [文件自动叠放与 QuickLook](11-file-stacks-and-quicklook.md)。

## 删除格子时，先分清是在删入口还是删文件

映射格子删除的是 DeskBox 中的入口，映射目录中的原文件仍留在磁盘上。收纳格子删除时，DeskBox 会提示对应收纳目录怎样处理。

有些收纳目录因为格子被删除、导入失败或路径迁移而暂时没有对应入口。它们会出现在维护功能的孤立收纳目录列表中。你可以恢复格子、打开目录、把内容移回桌面，或者确认后移到回收站。

文件格子配置的备份主要保护格子关系、应用数据和相关附件。外部映射目录仍建议使用版本控制、文件历史记录、云盘或其他独立备份方案。

## 一个能用很久的四格起点

如果现在的桌面已经很乱，也不用先想出一套完美分类。下面这四个格子能覆盖大多数日常动作。

1. **待处理** 用来接新文件。
2. **当前项目** 映射正在做的项目目录。
3. **常用资料** 映射模板、参考资料或高频文档。
4. **输出与交付** 收纳已经完成、等待发送的成果。

文件先进入待处理，项目开始后进入当前项目，完成后再放到输出与交付。用上一两周后，再决定是否需要为截图、安装包或某类素材拆出独立格子。

## 常见问题

### 文件格子会把电脑里的文件复制一份吗

收纳格子在拖入时会按你选择的复制或移动执行。映射文件夹只连接已有目录，不会复制目录内容。

### 我能直接把文件拖到微信吗

可以。微信当前窗口接受 Windows 文件拖放时，从展开的文件格子拖出真实文件即可进入发送流程。

### 删除一个映射格子会删掉项目目录吗

删除映射格子只移除 DeskBox 入口。格子内主动删除文件和文件夹时，操作仍会影响真实目录。

### 自动叠放会不会把图片收进新文件夹

不会。自动叠放改变的是格子内的视觉分组，真实目录结构保持不变。
