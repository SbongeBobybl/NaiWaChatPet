# DeskBox 60–90 Second Demo Script

Format: 16:9, 1440p or 1080p, silent by default, English captions burned in, cursor visible, no voiceover required. Export a 60–90 second master and a 15–25 second cut.

## Master sequence

| Time | Picture | Caption |
| ---: | --- | --- |
| 0–5 s | A real Windows desktop with screenshots, archives, documents, and shortcuts scattered across it. Hold long enough to read the mess. | `A familiar Windows desktop.` |
| 5–14 s | Open DeskBox from the tray. Show file widgets appearing on the existing desktop. | `DeskBox adds organization without replacing Explorer.` |
| 14–26 s | Drag several desktop files into a real-folder-backed file widget. Open the backing folder in Explorer briefly. | `Files remain ordinary local files and folders.` |
| 26–38 s | Map an existing work folder without moving it, then switch between icon and list views. | `Map existing folders. Move nothing.` |
| 38–49 s | Show desktop organization preview, then confirm one small batch. Keep the result readable. | `Turn clutter into a working space.` |
| 49–60 s | Switch Mica to Acrylic, collapse two widgets into capsules, then raise them once. | `Native-feeling WinUI 3 · Mica · Acrylic · Capsules` |
| 60–70 s | Briefly show search, todo, and quick capture. Limit each to one clear action. | `Search, todos, and notes stay close.` |
| 70–82 s | Return to the organized desktop. Show logo and product line over the real screen, not a synthetic mockup. | `Free · Open Source · Local-first · x64 + ARM64` |
| 82–90 s | End card with website and GitHub. | `deskbox.fun · github.com/Tianyu199509/DeskBox` |

## Short cut

Use shots 1, 3, 5, 6, and the end card. Keep the transformation legible; do not accelerate cursor movement until it becomes difficult to follow. Recommended duration: 20 seconds.

## Capture checklist

- Use the English interface and a clean test Windows account.
- Use believable files with no personal names, tokens, work documents, or private notification content.
- Keep desktop wallpaper neutral and avoid third-party branding.
- Record the full screen at native resolution; crop only during edit.
- Keep captions inside a 10% safe margin and readable at phone size.
- Do not claim a signed installer, SmartScreen reputation, download count, or performance figure unless verified for the final 1.3.8 build.
