# DeskBox 1.5.1 更新：大文件夹不再卡死，文件搬移更安全

**发布日期：2026 年 9 月 15 日 ｜ 版本 1.5.1**

DeskBox 1.5.1 是一次以「稳定与手感」为主的更新。这个版本修掉了打开超大文件夹时界面卡死的问题，让更换收纳路径、整理桌面这类文件搬移操作对只读文件和各种意外情况更宽容；同时也带来拖放打开、拖拽切换分组、Copilot 实体键热键等一批新能力，以及默认资源策略的调整。

## ✨ 新功能

**拖文件到应用快捷方式格子，直接用对应应用打开**
把文件拖到应用快捷方式格子上松手，即可用该程序打开这些文件。从桌面拖入和格子之间互拖都支持；目标不是可执行程序或无法验证时，仍按系统默认行为处理。

**拖着文件扫过分组标签，停一下就切换**
在多格子分组里拖动文件时，把文件悬停在某个分组标签上片刻即可自动切换到该格子，不用先放下文件再翻找。

**第 6 个全局热键预设：Copilot 实体键**
新款键盘上的 Copilot 键（多数键盘以 Win+Shift+F23 上报）现在可以直接绑定唤醒 DeskBox，并处理了该键「显示桌面」的特殊语义。

**点击收起模式下，点标题栏即收起**
使用「点击收起」模式时，单击格子标题栏即可直接收起；身份区在短暂的延迟窗口内仍保留双击语义，原有操作习惯不受影响。

**搜索弹窗新增「图片」「文档」结果 Tab**
搜索结果按类型分流到独立 Tab；切换 Tab 自动回到顶部，分类筛选随新查询自动重置。

**设置中新增应用内一键反馈**
在设置里即可打开反馈窗口，自动附带诊断上下文，反馈问题更省事。（反馈的实际送达依赖反馈服务后端的部署进度。）

**直装版自启动更规范**
直接安装版的开机自启改为注册最小权限的登录任务作为唯一入口，旧的注册表 Run 启动项只作为迁移来源；如果你在任务计划程序中禁用了该任务，DeskBox 不会绕过它。

## 🛠 修复

### 文件搬移与收纳更安全

这组修复同时覆盖「更换默认收纳路径」「拖文件夹进格子」「整理桌面」「删除格子时把内容移回桌面」四类操作：

- 格子文件夹里带只读属性的文件（聊天工具、网盘、邮件附件传来的文件常带此属性）不再导致搬移失败：清理源目录前会先解除只读，删除受阻时自动恢复原属性。
- 源目录只删除「已确认复制成功且未发生变化」的文件；搬移期间新出现或被修改的文件会在两边同时保留，绝不会被误删。
- 复制完成后旧目录清理受阻时，搬移正常完成并提供把残留目录移入回收站的选项，不再判为失败整体回滚；重试时若目标里还有上次的残留副本，会先提示清理，不再复制出一堆「名称 (2)」。

### 打开文件的反馈更诚实

- 双击没有文件关联的文件，现在会弹出系统「打开方式」选择器，而不是毫无反应。
- 打开目标已丢失的快捷方式，会明确提示目标丢失，不再谎报「已交给系统打开」。
- 拖入带隐藏属性或无法显示的快捷方式时整笔拒绝并给出反馈，文件不会再进了目录却凭空没有格子。
- 移除了打开成功的 toast 提示，并抑制点击后的选中残留，操作反馈更清爽。

### 搜索弹窗推荐区终于能点了

推荐应用区的鼠标操作自上线以来一直静默无效，现已修复：单击选中、双击打开、方向键加 Enter 启动高亮卡片；应用图标也在首次打开弹窗时即正确显示，不用再开第二次。

### 右键菜单不再拖慢整机

点击 Windows 原生右键菜单项时整机卡顿 1–2 秒的问题已修复：底层鼠标钩子从界面线程移到专职泵线程，菜单关闭即卸载。

### 胶囊过渡修复

收起格子后再次展开，标题栏不再残留轻微的上移错位；全新安装后首次展开胶囊，展开区中间不再残留胶囊图标与标题的「鬼影」。

### 图标不再「缩水」

部分应用图标因画布带大块透明边距而在格子里显示偏小，现在会按实际图形尺寸完整显示。

### 整理桌面恢复更可靠

不可恢复时的放弃操作有明确确认与诊断出口；孤儿恢复日志会被清理；同盘腾挪不再误触空间检查；报错信息更具体；格子映射冲突自动解决或揭示冲突格子，不再静默失败。此外，回收站第三级确认不再在 Smart 模式下弹不出，删除管理目录已空的格子时会顺带清掉空目录。

### 其他修复

- 重命名格子不再因一秒保存防抖窗口而留下空格子。
- 快捷唤起（托盘、热键）期间打开的搜索、随记等弹窗不再沉到置顶格子层的下面。
- 切换叠放活动成员不再闪现前一成员的瓦片。
- 搜索行选中指示条与文字中心对齐；行高缓存，并在懒加载元数据后重试高亮。
- 格子内的删除、重命名失败提示与取色器改为应用内反馈条和浮出控件，不再被小窗口裁剪。
- 清理孤儿待办数据；自动备份不再包含缓存目录。

## ⚡ 性能与内存

- **超大文件夹不再卡死**：文件格子对大文件夹改为窗口化渲染，滚动时按需加载更多行，上千文件的文件夹即开即用。
- **全新安装首启更快**：Shell 图标提取改为经缩略图代理单次批量请求，不再逐项往返。
- **全新安装默认「节省资源」预设**：可见空闲 5 分钟后维护、隐藏 30 秒后释放全部可重建缓存、较小的缓存预算；实验性的「隐藏后立即裁剪工作集」改为隐藏 3 秒后执行，连续隐藏/显示最多裁剪一次。**升级安装不会改写你现有的任何设置。**
- **交互更跟手**：框选改为增量应用；显示器插拔与分辨率变化改为事件驱动，不再 2 秒轮询；退役空闲动画栈，消除后台动画开销。
- **胶囊动画更精准**：只动画过渡真正变化的属性，动画期间的窗口边界提交批量合并，展开第一帧不再有启停顿挫。

## 🎨 界面

- 组拖放预览描边、胶囊位置指示点、标题滚轮反馈等交互元素改用中性交互色，不再跟随强调色，亮暗主题切换即时正确刷新。
- 瓦片、搜索行、随记卡片与待办条目的圆角收敛到更紧凑的档位，整体观感更利落。

## 📦 获取与升级

- **应用内更新**：设置 → 更新，检查并安装新版本。
- **官网 / GitHub Releases**：下载 x64 与 ARM64 直发安装包（Full AOT 构建，内置 Windows App Runtime，无需单独安装运行时）。
- **Microsoft Store**：商店版本在发布流程后段同步上架。

升级不会改动你的数据与既有设置，数据快照备份照常工作。遇到问题欢迎通过设置里新加的一键反馈（1.5.1 新增）或 GitHub Issues 告诉我们。
