# DeskBox 1.3.5

DeskBox 1.3.5 was prepared on August 3, 2026. Desktop organization, automatic organization, and widget groups were not part of 1.3.4; they are introduced in this release together with safer file movement, stronger search/index recovery, and Windows lifecycle compatibility.

## Highlights

### Desktop organization — new in 1.3.5

- The organization window now uses responsive cards that preview the files in each category, the target widget or new folder, the items that will stay on the Desktop, and the final storage location.
- Cards keep a fixed, readable icon layout while the window wraps them across columns and scrolls within each card; selection and destination are controlled per card.
- Each card can be enabled independently and can target a new folder or an existing widget; the window explains where files will be moved and lists concrete items that will not move.
- Growing downloads, temporary extensions, archive extraction, and same-path replacements wait for a stable terminal state instead of being moved while still in progress.
- The large-file limit is now 100 MB. Failed or incomplete baseline scans stay out of the committed baseline and retry through one generation-aware scheduler.

### Widget groups — new in 1.3.5

- File widgets can be merged, switched with the title wheel, detached by holding the title, or dissolved while preserving member positions and temporary-layer order.
- Merge hit testing is limited to the title region, and floating or hidden-title widgets can join a group and adopt its standard or compact presentation.

### File widgets and mapped folders

- Folder enumeration now distinguishes real empty folders from partial, unavailable, and access-denied results, so a disconnected drive does not look like an empty folder.
- Mapped folders keep their last known snapshot while a network or cloud location reconnects, and watcher generations prevent events from an old mapping entering a new path.
- Refreshes preserve manual ordering and retain the previous count when a temporary enumeration fails; retries are visible through folder health diagnostics.

### Search and indexing

- Search roots use manifests and safe reconciliation: partial, capped, offline, permission-limited, or cancelled scans no longer erase valid indexed results.
- NTFS USN journal changes are applied incrementally for create, delete, rename, and hard-link updates, with journal-gap recovery and directory-index fallback.
- Watcher failures, offline roots, scan coverage, USN status, and recent full-scan time are available to diagnostics instead of appearing as a generic “not updated” state.

### Dragging and sorting

- Cross-screen file reordering no longer mutates the list on every DragOver. A breathing theme-colored insertion line appears between the neighboring items and the final order commits once on drop.
- Standalone file widgets and grouped file surfaces share the same realized-container insertion calculation, keeping auto-scroll and virtualization behavior consistent.
- File-to-folder drops, blank-area sorting, external drag-out, and grouped surfaces use clearer target rules and consistent success feedback; nested-path checks run before both mapping and drop execution.

### Windows compatibility and lifecycle

- Secondary windows choose Mica, Desktop Acrylic, or a theme-colored solid fallback according to the capabilities of the current Windows version.
- Animations respect reduced-motion and high-contrast settings, while sleep, unlock, RDP, Explorer restart, and display changes trigger lightweight health checks and recovery.
- Startup z-order is normalized so widgets promoted from temporary layers do not remain behind or split across layers after the first launch.

### Release notes, localization, and polish

- Settings can open the latest release notes in a separate window with safe Markdown rendering; Chinese users prefer Chinese content and other locales use English, with English fallback when Chinese text is missing.
- Five language resources were synchronized for the new settings, diagnostics, drag feedback, organization, and release-note text.
- File icons, drag-out feedback, group title interactions, menu states, and window sizing received smaller consistency fixes; automated tests cover the new reliability paths.

## Compatibility

- Windows 10 21H2 is the minimum platform; Windows 10 22H2 and Windows 11 are the primary compatibility validation targets.
- x64 and ARM64 remain the supported architectures. The normal direct distribution remains framework-dependent and uses the matching .NET 10 and Windows App Runtime 2.2 runtimes.

## 中文说明

DeskBox 1.3.5 于 2026 年 8 月 3 日准备发布。1.3.4 不包含桌面整理、自动整理和格子组；本版本首次加入这些能力，并同步完善文件同步、搜索索引、拖动安全性和 Windows 生命周期恢复。

### 桌面整理（1.3.5 新增）

- 整理窗口改为响应式卡片，执行前可以看到每类文件、目标格子或新建格子、不会移动的项目和最终收纳位置。
- 卡片保持易读的固定图标布局，窗口变宽时增加列数、变窄时自动换行；每个卡片单独控制是否整理和目标位置。
- 每个卡片可以单独勾选，并选择新建文件夹或已有格子；面板会解释文件将被移动到哪里，并列出具体不会移动的项目。
- 正在增长的下载、临时后缀、压缩包解压和同路径替换会等待稳定终态，不会在文件尚未完成时移动。
- 大文件限制调整为 100 MB；枚举不完整或整理失败时不会写入新的 baseline，并由统一的代次重试调度继续处理。

### 格子组（1.3.5 新增）

- 文件格子可以合并、使用标题滚轮切换、长按标题拖出或解散，并保留成员位置和临时层级。
- 合并命中限定在标题区域，悬浮/隐藏标题格子也能加入组，并自动采用组的标准或紧凑样式。

### 文件格子与映射文件夹

- 文件夹枚举区分真实空目录、部分结果、不可用和无权限，网络盘断开时不会被误判为空目录。
- 映射目录重连期间保留上次内容快照，watcher 代次会阻止旧映射事件进入新路径。
- 刷新不再破坏手动排序，临时计数失败会保留旧值并等待重试；文件夹健康状态可在诊断中查看。

### 搜索与索引

- 搜索根目录使用清单和安全对账，部分扫描、容量上限、掉线、权限不足或取消时不会误删已有结果。
- NTFS USN journal 支持创建、删除、重命名和硬链接变化的增量处理，并在 journal 断档时恢复或回退到目录索引。
- watcher 失败、离线根目录、扫描覆盖范围、USN 状态和最近完整扫描时间会进入诊断信息。

### 拖动与排序

- 跨屏文件排序不再在每次 DragOver 时修改列表；相邻项目之间会显示主题色呼吸插入线，松开鼠标时一次提交最终顺序。
- 独立文件格子和格子组内文件格子共用插入位置计算，虚拟化和自动滚动时的行为保持一致。
- 文件拖到文件夹项目时执行移动，拖到空白区域时执行排序；外部拖出、组内拖动和嵌套路径检查使用统一的目标与结果反馈。

### Windows 兼容与生命周期

- 次级窗口按系统能力选择云母、桌面亚克力或主题色纯色背景回退。
- 动画遵守减少动态和高对比度设置；休眠、解锁、RDP、Explorer 重启和显示器变化后会执行轻量健康检查与恢复。
- 首次启动统一临时层级，避免格子在顶部和底部被拆成不同层级。

### 更新日志、多语言与细节

- 设置可在独立窗口查看最新版本更新内容，并使用安全的简单 Markdown 渲染；中文优先显示中文，其他语言显示英文，中文缺失时回退英文。
- 五种语言资源同步补齐设置、诊断、拖动反馈、桌面整理和更新日志文案。
- 文件图标、拖出提示、格子组标题交互、菜单状态和窗口尺寸继续做一致性优化，并增加新的稳定性测试。

## 兼容性

- Windows 10 21H2 为最低系统版本；Windows 10 22H2 和 Windows 11 是本版本的主要兼容性验证目标。
- 继续支持 x64 与 ARM64；直接分发版本为框架依赖模式，使用对应架构的 .NET 10 和 Windows App Runtime 2.2。
