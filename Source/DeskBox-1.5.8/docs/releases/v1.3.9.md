# DeskBox 1.3.9

DeskBox 1.3.9 focuses on interactions that previously looked stuck or behaved differently depending on where they were used. Capsule expansion, startup restore, multi-item drag, large transfers, group-title scrolling, and first-run guidance now follow clearer state rules.

## Highlights

- **Capsules stay predictable.** Smart auto-hide reads the real pointer position when enabled, retries a blocked collapse, limits simultaneous resize animations, and keeps the active expanded capsule above other DeskBox widgets.
- **Widgets return after launch.** Every enabled standalone widget and the active surface of each group is restored for the new session and shown in a temporary foreground state.
- **Multi-item drag keeps the batch.** File widgets, search results, standalone Quick Capture, and grouped Quick Capture preserve the full selection. Mixed files and folders remain together.
- **Large transfers explain their state.** The progress card appears during preparation, remains indeterminate until a byte total is known, and changes to Canceling immediately after the button is pressed.
- **Cancellation protects the batch.** Cross-volume moves can stop during streamed copying, and canceled batches roll back completed work where possible.
- **Group-title scrolling completes reliably.** Wheel navigation wraps through members and waits for the pending switch to finish.
- **Onboarding is shorter and visual.** New users see one introduction, two optional real exercises, and a final choice. Managed drops are described as Move by default, and exercises complete only after a real operation succeeds.

## Download and verification

The GitHub Release provides framework-dependent installers for both architectures.

- `DeskBox_Setup_1.3.9_x64.exe` supports most Intel and AMD PCs.
- `DeskBox_Setup_1.3.9_arm64.exe` supports native Windows on ARM PCs.
- Each installer is accompanied by a SHA-256 sidecar.

The installer reuses compatible .NET 10 Runtime and Windows App Runtime 2.2 installations and downloads only a missing architecture-matched dependency.

## 中文说明

DeskBox 1.3.9 集中处理那些容易让人误以为卡住，或在不同位置表现不一致的交互。胶囊展开、启动恢复、多选拖拽、大文件传输、格子组滚轮和新手引导现在使用更清楚的状态规则。

## 更新亮点

- **胶囊状态更可控。** 开启悬停自动展开时会读取真实鼠标位置，暂时无法收起时会继续重试，并限制同时执行的尺寸动画。当前展开的胶囊会保持在其他 DeskBox 格子上方。
- **启动后恢复所有格子。** 每个已启用的独立格子，以及格子组当前使用的页面都会在新会话中恢复，并以临时前景状态显示。
- **多选拖拽不再漏项。** 文件格子、搜索结果、独立随记和组内随记都会保留完整选择，文件与文件夹混合拖动也不会丢失路径。
- **大文件传输会说明当前状态。** 准备阶段就会出现进度卡片，总大小未知时显示不确定进度，点击取消后立即显示取消中。
- **取消操作会保护整批内容。** 跨盘移动可以在流式复制期间停止，取消整批操作时会尽量撤回已经完成的内容。
- **标题滚轮切换更可靠。** 滚轮可以循环切换组成员，并会等当前目标真正完成后再继续。
- **新手引导更短也更直观。** 新用户会看到一屏介绍、两次可跳过的真实练习和结束选择。收纳拖入明确采用默认移动，练习只在真实操作成功后完成。

## 下载与校验

GitHub Release 提供两种框架依赖安装包。

- `DeskBox_Setup_1.3.9_x64.exe` 适用于大多数 Intel 和 AMD 电脑。
- `DeskBox_Setup_1.3.9_arm64.exe` 适用于原生 Windows on ARM 电脑。
