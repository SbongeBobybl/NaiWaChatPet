# DeskBox 1.5.5

DeskBox 1.5.5 introduces cloud backup to your own WebDAV server with scoped, tombstone-safe restore, reworks file drag-and-drop so Copy-only targets (VS Code, browsers, legacy programs) accept DeskBox drags and cross-volume transfers run through the system file-operation engine, and makes hotkeys self-heal when Windows silently strips their hooks. It also adds idle working-set trimming for visible widgets, a Fluent-style snap-alignment edge band, per-widget capsule expansion direction, drag-to-reorder capsule bars, a window-shadow toggle, and interactive storage migration. Restore is hardened end to end: deletions leave tombstones so merged restores stop resurrecting locally deleted entries, accepted-but-unverified uploads surface as "awaiting server confirmation", and archive size caps are enforced on the bytes actually extracted.

Release date: 2026-09-22 (prepared from the `feat/roadmap-batch-2b-sync-pinvoke` working tree, PR #403 plus the in-flight hardening batch).

## Highlights

- **Cloud backup to your own server.** Settings → Maintenance gains a WebDAV cloud-backup page: per-domain toggles (todo, quick capture, widget style), configurable interval and retention, credentials in Windows Credential Manager, "Test connection" against what you just typed, on-demand backups, and a browsable remote snapshot list.
- **Scoped cloud restore.** Pick which data domains come back — todo, quick capture, widget style — and choose merge (newer `UpdatedAt` wins, nothing on this device is deleted) or a full snapshot-faithful restore. Restores stage into an isolated directory, validate, write a pending marker, and apply on the next launch with a pre-restore safety archive pinned first. The confirmation dialog shows per-domain item counts.
- **Drag-and-drop that works everywhere.** File drags out of widgets carry the same native Shell data object Explorer uses, so Copy-only drop targets that used to reject DeskBox — Chromium/Electron apps, WM_DROPFILES-era programs, WinForms — now accept them. Same-volume drops default to move, cross-volume to copy, Ctrl/Shift/Alt behave as expected on Windows 11, and Windows 10 keeps single-move without prompting.
- **Cross-volume transfers through the system engine.** Cross-volume moves and copies now use IFileOperation with native progress, cancellation, and conflict handling, fixing the Native AOT cross-volume import that completed with "0 items". Aborted transfers clean up only the objects they created.
- **Hotkeys that heal themselves.** Windows can silently strip low-level hooks under memory pressure, leaving the global hotkey, search hotkey, or desktop double-click activation dead until restart. A two-stage health watchdog (divergence check, tagged canary, cooldowns) now detects and re-registers them.
- **Deletions survive merges.** Quick capture and todo deletions now write stripped tombstones (id + timestamps only, payload removed). A remote snapshot can no longer resurrect an item you deleted locally, and a remote tombstone never overwrites a live local item.
- **Honest backup status.** An upload the server accepted but whose listing never converged is recorded as "awaiting server confirmation": the settings status row marks it, and a scheduled run notifies once per session — a laggy WebDAV listing can no longer hide a silently-dropped snapshot, nor can it false-alarm as a failure.
- **Idle memory trimming.** Widgets can return memory to Windows after a few seconds of true quiet, not only when everything is hidden. Trimming is gated by an absolute working-set floor, a post-trim growth guard, and ambient-animation awareness; hidden-session and idle trims no longer double-fire. Controlled by the new "Trim memory when idle" performance option.
- **Fluent-grade snap feedback.** The looping breathing glow is replaced by a thin accent edge band that settles once, dissolves around rounded corners, and fades perpendicularly into the widget — on both sides of a snapped pair.
- **Capsule control.** Per-widget expansion direction override (auto / down / up) from the collapse menu, drag-to-reorder for capsule bars including cross-monitor reanchoring, and manual ordering that survives restore and rearrange flows. New groups default to tab navigation.
- **Sharper shortcuts, honest icons.** Alt-dragged shortcuts keep the target's own icon; arrow-overlaid shortcuts render through a high-resolution compositing channel (256 px JUMBO overlay) instead of pre-scaled bitmaps, with a 32 px fallback.
- **Material honesty.** A one-time hint explains when Mica/Acrylic degrade to a solid color — now also firing the moment transparency effects or battery saver flip mid-session.

### Also fixed (user-visible)

- The settings window no longer freezes on the theme it had when it was closed; it follows system light/dark again.
- The cloud-backup page no longer crashes with "Specified cast is not valid" on Native AOT builds (real WebDAV user report).
- Leftover folders from closed widgets no longer block creating a same-named widget — the empty widget adopts the folder and its contents.
- Migration rollback failures explain themselves with a retry dialog, and no longer loop on locked files or wait on closed dialogs.
- The in-app feedback dialog no longer sticks on "Submitting…" after timeouts; folder-conflict messages name the other widget and the exact conflict.
- Association-less files open through DeskBox's own picker with honest results; the shell picker's cancelled run no longer counts as success.
- Cloud backups exclude todo/quick-capture attachments; restores never delete local attachments.
- Transfer errors distinguish "file in use" from "access denied"; the Win32 error re-read that garbled messages is fixed.

See `CHANGELOG.md` for the complete list, including upgrade reliability (device-local layout store, paired layout+settings commits, journaled style restore).

## 中文说明

DeskBox 1.5.5 带来云备份域作用域还原（合并或完全恢复）、可见格子的空闲内存修剪、Fluent 风格吸附边缘光带、单格子胶囊展开方向与胶囊条拖拽重排。同时端到端加固了还原链路：删除现在会留下墓碑，合并还原不再复活本机已删条目；已接收但未验证的上传标注"等待服务器确认"而非看似成功；归档大小上限按实际解出的字节数强制执行。

2026 年 9 月 21 日发布（产自 `feat/roadmap-batch-2b-sync-pinvoke` 工作区，PR #403 加上在途加固批次）。

### 主要更新

- **域作用域云还原。** 可选回哪些数据域——待办、随记、格子样式——并选择合并（`UpdatedAt` 新者胜出、不删除本机数据）或严格按快照的完全恢复。还原先暂存到隔离目录、校验、写入待还原标记，下次启动时应用，且先固定还原前安全备份。
- **删除在合并中存活。** 随记与待办删除现在写入剥离式墓碑（仅保留 id 与时间戳，载荷移除）。远端快照无法再复活本机已删条目，远端墓碑也永远不会覆盖本机存活项。
- **诚实的备份状态。** 服务器已接收但列表始终未确认的上传记为"等待服务器确认"：备份状态行会标注，定时运行每次会话最多通知一次——列表延迟的 WebDAV 既无法掩盖悄悄丢失的快照，也不会误报为失败。
- **空闲内存修剪。** 格子在几秒真实静默后即可向 Windows 归还内存，不再要求全部隐藏。修剪受绝对工作集下限、修剪后增长门与常驻动画感知保护；隐藏会话与静默修剪不再重复触发。由新的"空闲时修剪内存"性能选项控制。
- **Fluent 风格吸附反馈。** 循环呼吸辉光改为细窄的 accent 边缘光带，落定一次后稳定，在圆角处消融，并向格子内部垂直渐隐——吸附成对时两侧对称。
- **胶囊控制。** 收起菜单可单独覆盖展开方向（自动/向下/向上），胶囊条支持拖拽重排（含跨显示器重锚），手动排序在还原与重排流程中更可靠地保留。
- **材质提示。** Mica/亚克力降级为实色时给出一次性说明——现在在会话中途关闭透明效果或开启省电模式的瞬间也会提示。

完整条目见 `CHANGELOG.md`。
