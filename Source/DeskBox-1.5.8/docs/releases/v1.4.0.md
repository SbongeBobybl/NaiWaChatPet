# DeskBox 1.4.0

DeskBox 1.4.0 is a substantial Todo and Quick Capture workspace release. It brings both widgets onto a shared responsive list/detail foundation, adds native Markdown editing, simplifies their settings, and closes several reliability gaps in capsule hover, desktop layering, live settings, attachments, weather views, and idle memory cleanup.

## Highlights

- **One responsive workspace.** Todo and Quick Capture switch safely between focused single-pane and adjustable dual-pane layouts. Standalone and grouped hosts now follow the same rules.
- **Native Markdown editing.** The shared editor supports formatting, tasks, tables, safe preview, source-preserving commands, and configurable Enter behavior while keeping legacy plain-text records compatible.
- **Settings with less nesting.** Both feature pages put the main switch first, keep wide-layout behavior nearby, group related controls in native expanders, and combine related display choices.
- **Capsules keep expanding after a member switch.** Hover state is reconstructed from the real pointer, title controls support a deliberate dwell, and segmented tabs are prepared before the expansion becomes visible.
- **Desktop widgets return to their layer.** Temporary raises are tracked as a batch and released safely after interaction, including when stale callbacks arrive later.
- **Idle memory cleanup runs after 30 seconds.** Hidden surfaces perform a soft cleanup, and visible but untouched DeskBox surfaces can release caches and eligible managed memory without interrupting active work.
- **Live preferences stay live.** Weather views, Quick Capture layout and tabs, preview lines, editor shortcuts, materials, and attachment removal are applied by the active shared hosts.

## 中文说明

DeskBox 1.4.0 是一次较大规模的待办与随记工作区更新。两类格子统一到响应式列表/详情基础结构，加入原生 Markdown 编辑，重新整理设置层级，并修复胶囊悬停、桌面层级、设置即时生效、附件删除、天气视图和空闲内存回收等问题。

## 更新亮点

- **统一响应式工作区。** 待办与随记可以在聚焦单栏和可调双栏之间安全切换，独立窗口与格子组遵循同一套规则。
- **原生 Markdown 编辑。** 共享编辑器支持格式、任务、表格、安全预览、保留源文的命令和可配置回车行为，同时兼容已有纯文本记录。
- **减少设置层级。** 两个功能页都将总开关放在顶部，紧接宽屏布局；同类内容使用原生风琴，相关显示项合并选择。
- **切换成员后仍可悬停展开。** 根据真实鼠标重建悬停状态，标题控制区支持稳妥停留展开，顶部分段标签会在动画可见前准备完成。
- **桌面格子会回到正确层级。** 临时前置按整批追踪并在交互结束后安全释放，旧回调也不会干扰新的置顶状态。
- **空闲 30 秒后自动回收。** 全部隐藏时执行轻量清理；格子仍显示但 DeskBox 未被操作时，也可以释放缓存和符合条件的托管内存。
- **设置立即影响当前界面。** 天气视图、随记布局与标签、预览行数、编辑快捷键、纸张材质和附件删除都已接入共享宿主。
