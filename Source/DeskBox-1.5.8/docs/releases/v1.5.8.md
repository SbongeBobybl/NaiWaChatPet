# DeskBox 1.5.8

DeskBox 1.5.8 is an integrity and maintenance release built around one theme: DeskBox and the shell it lives in should sit at the same integrity level, and when they cannot, the app explains what happened instead of showing an unrelated warning. The "running as administrator" notice now appears only when DeskBox really runs above the shell: fully elevated desktops (company-managed machines with forced elevation, UAC-off machines) no longer receive the 1.5.7 notice that described drag as broken even though it worked there; the notice exits the elevated instance in one click and walks the user through a normal restart, including how to clear a shortcut's "Run as administrator" checkbox — a per-shortcut elevation source the compatibility-layer scan can never see, which the drag-and-drop diagnostic now detects and explains on its own. One-click updates stop feeding the loop: the updater restarts the app at the shell's own level whenever the shell offers a standard-user context, so an elevated machine's update no longer lands the app back in administrator mode. When Explorer itself runs elevated above DeskBox (the reverse direction), startup no longer kills the session over a UIPI-blocked tray icon: the reveal hotkey and settings stay reachable, an explanatory notice appears, and the rare fatal-startup dialog is localized and lists the diagnosed environment causes. The maintenance wave lands alongside: Todo-widget drags no longer crash, switching groups no longer loses stacked-member icons, cutting a subfolder and pasting it into its parent no longer hangs, auto-organization rules survive restarts, a crashing desktop no longer drags DeskBox into a logon restart loop (a startup ledger breaks the cycle and diagnostics now carry recent DeskBox/Explorer crash events), an update-download failure no longer errors when another dialog is open, and an instance relaunched with normal privileges is terminable again by an unelevated Task Manager.

Release date: 2026-10-14 (content prepared from the working tree of `fix/icon-ledger-engine-unification` following `61f151f3` — the 1.5.7 release commit — including the integrity-asymmetry batch, the four-debt closure, the icon-ledger/transport-engine unification, the boot-restart-loop ledger batch, and the Todo drag fixes).

## Highlights

- **Accurate administrator notices (field reports, 2026-10-14).** The elevation gate's verdict now comes from a single asymmetric predicate — DeskBox elevated above the shell warns and offers a one-click exit; both sides equal (including fully elevated desktops) stay silent. 1.5.7 had warned same-level machines with a text that claimed UAC was off and drag was broken, neither of which held there; two field diagnostic packages traced those reports to the notice text — their logs contained no failed drags. The notice's interactive form changed from a self-relaunching button to "exit and restart normally": the shell-parented relaunch child landed on a startup path whose raised-reveal state starved drags on the current tree, and self-serve keeps every restarted instance on the field-proven plain path. Autostart keeps its silent self-heal.
- **Updates stop bringing DeskBox back as administrator.** The updater inherits the app's token: on an elevated machine the post-update restart used to land elevated, which is the loop entry the first field report hit. The updater now restarts the app at the shell's own level whenever the shell offers a standard-user context (a shared `ShellUnelevatedLaunch` primitive with the app's gate), and deliberately keeps inheriting on fully elevated desktops, where matching the shell is what keeps the tray and drag working.
- **Graceful under an elevated Explorer.** A Medium DeskBox under a High Explorer loses its tray icon to UIPI (15/15 creation failures); 1.5.7's startup lifeline treated "no tray + no widgets" as fatal and ended an otherwise healthy session on every launch (field report: "the app won't open"). The lifeline now counts a registered global hotkey as a usable surface, the degraded session survives with an explanatory notice, and the fatal-startup dialog is localized and appends the diagnosed environment causes (elevated Explorer, compatibility layers, shortcut run-as).
- **Maintenance wave.** Todo-widget drag crash fixed (dual drag initializers); switching groups no longer loses stacked-member icons (icon-freshness ledger); subfolder cut → parent paste hang fixed by retiring the legacy shell-operation bridge onto the unified modern engine; auto-organization rules stay enabled across restarts; a logon restart loop driven by a crashing desktop is broken by the startup storm guard, with crash events recorded into diagnostics; an update-failure dialog no longer throws when another dialog is open (the coordinator now catches the COMException form of the ContentDialog collision); the drag diagnostic detects shortcut-level "Run as administrator" via the link-header flag; and a process relaunched at shell level carries a normalized DACL and integrity label, so standard tools can end it again (the elevated creator used to stamp a High label that no-write-up enforced over the granted rights).

## 中文说明

DeskBox 1.5.8 是完整性与维护版本，围绕一个主题：让 DeskBox 与资源管理器保持在同一完整性级别；无法保持时给出准确的说明。「以管理员身份运行」提示只在 DeskBox 以高于资源管理器的权限运行时出现：全桌面提权的电脑（公司统一管理机、UAC 关闭机）不再显示 1.5.7 升级后那条与实际不符的提示（两份野外诊断包显示，相关反馈源于提示文案本身，日志中并没有失败的拖拽记录）；提示窗改为「退出 DeskBox」+ 引导普通方式重启，并教会用户取消快捷方式的"以管理员身份运行"勾选——这是兼容层扫描永远看不见的按快捷方式提权来源，拖拽诊断现已能独立识别并给出精确取消路径。一键更新不再以管理员身份重启应用：只要资源管理器提供标准用户环境，更新器就按其权限级别重启应用。反向场景（资源管理器以管理员运行、高于 DeskBox）不再结束整个会话：托盘被 UIPI 拦死时热键与设置保持可用并弹出说明窗，极少出现的启动失败弹窗已本地化并列出诊断到的环境成因。维护波次随版落地：待办拖拽不再崩溃、切组不再丢叠放图标、子目录剪切粘贴回原处不再卡死、自动整理规则跨重启保持、桌面崩溃循环被启动账本切断且诊断包携带崩溃事件、更新失败弹窗不再与其它对话框冲突、普通权限重启的实例重新可被未提权的任务管理器结束。

### 主要更新

- **更准确的管理员运行提示（2026-10-14 野外反馈）。** 提权判定收敛到单一非对称谓词：DeskBox 高于 Shell 才提醒并提供一键退出；双方同级（含全桌面提权）保持沉默。1.5.7 曾对同 1 级机器弹出"UAC 已关闭、拖拽已坏"的与实际不符的提示。交互形态从"自动重启"改为"退出+自助重启"——自动重启的子进程会经过当前树上拖拽饿死的启动路径，自助重启让每个实例都走久经验证的普通路径；开机自启的静默自愈保留。
- **更新不再带回管理员。** 更新器继承应用令牌，提权机器的更新重启此前必落管理员（第一位野外用户的循环入口）。更新器现在只要 Shell 提供标准用户环境就按 Shell 级别重启（与应用侧共用 ShellUnelevatedLaunch 原语）；全提权桌面则刻意保持继承——与 Shell 同级正是托盘与拖拽正常的前提。
- **资源管理器提权时优雅降级。** Medium 的 DeskBox 在 High 的 Explorer 下托盘创建被 UIPI 全数拦截；1.5.7 的启动生命线把"无托盘+无格子"判定为致命错误，导致每次启动都会结束会话（野外反馈为"打不开"）。生命线现在把已注册热键计为可用面，降级会话存活并弹出说明窗；启动失败弹窗本地化并附带诊断成因（Explorer 提权、兼容层、快捷方式管理员勾选）。
- **维护波次。** 待办拖拽崩溃、切组丢叠放图标、子目录剪切粘贴卡死、自动整理规则被关、登录重启循环（启动账本+崩溃事件入诊断）、更新失败弹窗互斥、快捷方式管理员勾选诊断、普通权限重启实例的可终止性（DACL+完整性标签归一化）。
