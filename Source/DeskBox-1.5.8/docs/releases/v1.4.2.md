# DeskBox 1.4.2

DeskBox 1.4.2 was released on August 16, 2026.

This update focuses on the parts people touch every day. File stacks are easier to control, capsule placement is predictable, Todo and Quick Capture handle content more reliably, and repeated widget operations feel smoother.

## Todo and Quick Capture

- Todo checkmarks stay with the intended task. Unchecking an item in Completed removes only that task without changing the next row.
- Single-pane Todo detail uses a clear back arrow and removes the duplicate completion control. Header actions have more consistent spacing and a compact frosted background.
- Clipboard images show thumbnails in Quick Capture lists and details. Copying an image record writes the image itself back to Windows.
- Todo and Quick Capture share equal-size attachment tiles with image previews, file icons, horizontal scrolling, and hover removal.
- Records and Pinned keep their empty views after repeated tab changes. Pinned has its own add card and creates pinned content directly.
- Meaningful Quick Capture drafts are saved before navigation, while empty drafts no longer block selection or create blank records.
- Newly created Todo and Quick Capture widgets include editable localized guides. Resetting their data restores the matching guide.
- Markdown tables, code, links, task lists, emphasis, and pasted images render more consistently, with readable colors in light and dark themes.
- Quick Capture search opens in the tab row instead of adding another line. Clear removes the query, while Cancel or Esc closes search and restores the tabs.

## File widgets, stacks, and QuickLook

- Manual stacks remain available when automatic stacking is disabled. Editing the members or order of an automatic stack converts it to manual control so later rule updates do not overwrite the change.
- Files can be dragged into a stack from File Explorer, a browser, or another file widget. Members can be removed individually, the entire stack can be dissolved, and one-member stacks dissolve automatically.
- Dragging an item out of a widget no longer changes the widget's sorting mode. Reordering inside a stack stays local to that stack.
- Stack expand and collapse transitions have dedicated motion, keyboard handling, focus recovery, and clearer ownership cues. Drop highlights and pulsing borders disappear when the drag ends.
- File-type and custom stacking rules follow the selected mode independently, avoiding unexpected groups produced by combined rules.
- Files and applications opened from file widgets launch through the Explorer desktop shell. They receive the same user environment as desktop-launched items, improving compatibility with local development tools, services, and globally installed integrations.
- QuickLook can continue from the edge of one file widget into an adjacent visible file widget using the arrow keys.

## Capsule mode, widget groups, and desktop layer

- Capsule expansion direction can be set to Auto, Down, or Up. Fixed directions keep the title edge anchored, including after hiding and restoring widgets with F7.
- Hover auto-expand reconnects after mode changes, hiding, and restoring. Hiding a widget also clears stale hover state and the temporary drag mask.
- Widgets assigned to the desktop layer stay there when their title or empty area is clicked. Dynamic-layer widgets retain their temporary foreground behavior.
- Widget expand, collapse, and resize animations recover more cleanly when an operation is repeated or interrupted.
- One effective wheel step changes one group member and plays one background highlight, avoiding double jumps and repeated flashing.
- Circular first-to-last navigation remains available for continuous wheel movement.
- Newer switch requests replace unfinished older work without rolling back a member that is already visible.
- Collapsed groups show a compact position indicator, and widgets return to the expected desktop layer more reliably after interaction, display changes, or Win+D.

## Music and interface polish

- Play, pause, previous, and next use matching filled Windows-style transport icons. Repeat and volume remain compact auxiliary controls.
- Cover mode uses a taller frosted control strip, left-aligned song information, and a clearer single-line layout.
- Todo, Quick Capture, onboarding, desktop organization, and release notes use more consistent frosted action surfaces and spacing.
- Feature-widget settings use the same colorful icons as widget title bars. Several settings descriptions are shorter and easier to understand.
- The floating search handle uses an opaque light or dark color, removing the visible overlap in its center.
- The title-bar add button opens the same widget-creation menu from file, Todo, Quick Capture, music, weather, and search widgets. New tasks and notes still use the dedicated controls inside their workspaces.

## Onboarding, search, and smaller details

- The opening logo animation is slower, stays readable, and fades into the first step without shrinking toward the corner.
- Onboarding reaches the main actions more directly, while feature-widget choices apply immediately and remain synchronized with Settings.
- Background search refreshes keep unchanged rows, selection, and resolved icons, reducing visible rebuilding and flicker.
- Weekly high and low temperatures now match the visual scale of their day labels. Empty, hover, and compact states are more consistent across the app.

## 中文说明

DeskBox 1.4.2 已于 2026 年 8 月 16 日发布。

这次更新集中处理日常操作中最容易感受到的问题。文件叠放更容易控制，胶囊位置更稳定，待办与随记的内容操作更加可靠，连续操作格子时也更顺滑。

## 待办与随记

- 待办勾选始终对应实际任务。在“已完成”中取消勾选只会移出当前任务，不会影响下一项。
- 待办单列详情使用明确的返回箭头，并移除重复完成按钮。顶部操作间距更加统一，也加入紧凑的磨砂背景。
- 随记中的剪贴板图片会在列表和详情中显示缩略图，复制图片记录时写回的是图片本身。
- 待办与随记共用等尺寸附件方块，支持图片预览、文件图标、横向滚动和悬浮删除。
- “随记”和“固定”反复切换后仍会显示正确空状态。固定页加入新增卡片，从这里创建的内容会直接固定。
- 切换记录前会先保存有效草稿。空白草稿不会阻止选择，也不会创建空记录。
- 首次创建待办或随记格子时会加入可编辑的本地化说明，重置数据后也会恢复对应内容。
- Markdown 表格、代码、链接、任务列表、强调文字和粘贴图片显示更加稳定，浅色与深色主题下都能保持清晰。
- 随记搜索会在标签栏原位置展开，不再额外占用一行。清除按钮只清空关键词，点击“取消”或按 Esc 才会退出搜索并恢复标签栏。

## 文件格子、叠放与 QuickLook

- 关闭自动叠放后，手动创建的叠放仍会保留。调整自动叠放的成员或顺序后，该组会转为手动控制，后续规则更新不会覆盖用户操作。
- 支持从资源管理器、浏览器和其他文件格子直接拖入叠放。成员可以单独移出，也可以解散整个叠放，只剩一个成员时会自动解散。
- 将文件拖出格子不会意外切换格子的排序方式。叠放内部的排序只影响当前叠放。
- 叠放使用专门的展开与收起动画，并补齐键盘操作、焦点恢复和归属提示。拖放结束后，高亮和呼吸边框会立即消失。
- 文件类型与自定义叠放规则会按当前选中的模式分别生效，避免两套规则叠加后产生意外分组。
- 从文件格子打开文件或应用时，改由资源管理器桌面 Shell 执行。启动后的程序会获得与桌面启动一致的用户环境，本地开发工具、服务和全局扩展能够更可靠地读取已有配置。
- QuickLook 浏览到当前文件格子边界后，可以继续使用方向键切换到相邻的可见文件格子。

## 胶囊模式、格子组与桌面层级

- 胶囊展开方向新增“自动”“向下”和“向上”三种选择。固定方向会保持标题边缘作为锚点，F7 隐藏再显示后也不会发生位置漂移。
- 切换模式、隐藏或重新显示格子后，悬停自动展开会重新挂接。隐藏格子时也会清理旧的悬停状态和临时拖动遮罩。
- 固定在桌面层的格子，点击标题或空白区域后仍会留在桌面层。动态层级继续保留原有的临时前置交互。
- 格子展开、收起和尺寸变化在连续触发或中断后衔接更加稳定。
- 一次有效滚轮输入只切换一个格子组成员，并只播放一次背景提示，减少跳过两项和反复闪烁。
- 保留首尾循环，持续向同一方向滚动可以一直循环切换。
- 新的切换请求会接替尚未完成的旧请求，不会把已经显示的成员切回去。
- 收起后的格子组会显示简洁的位置指示。操作格子、切换显示器或按下 Win+D 后，格子也会更可靠地回到正确桌面层级。

## 音乐与界面细节

- 播放、暂停、上一首和下一首使用统一尺寸的 Windows 风格面性图标，循环和音量保持较小的辅助规格。
- 封面模式采用更高的磨砂控制条、左对齐歌曲信息和更清楚的单行布局。
- 待办、随记、新手引导、桌面整理和更新日志统一了磨砂操作区、边距和紧凑控件尺寸。
- 功能格子设置改用标题栏同款彩色图标，多项设置说明也进行了精简。
- 悬浮搜索窗口的拖动手势条会根据浅色或深色主题使用纯色，消除中间重叠发灰的问题。
- 文件格子、待办、随记、音乐、天气和搜索的标题栏添加按钮统一打开格子创建菜单。新建任务和笔记继续使用内容区内的专用入口。

## 新手引导、搜索与其他细节

- 开场 Logo 动画放慢并延长文字停留时间，通过渐隐平滑进入第一步，不再向左上角缩小。
- 新手引导更直接地介绍主要操作，功能格子开关会立即生效，并与设置页保持同步。
- 搜索结果后台刷新时会保留未变化的结果、选择状态和图标，减少列表重建与闪烁。
- 天气周视图的高低温与日期标签使用统一视觉比例，多处空状态、悬浮状态和紧凑控件也完成统一。
