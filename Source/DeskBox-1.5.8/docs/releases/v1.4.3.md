# DeskBox 1.4.3

DeskBox 1.4.3 was released on August 19, 2026.

This update improves Windows 10 widget interaction while preserving real-window resize, capsule, and full-widget transitions. It also adds Traditional Chinese throughout the app and installer.

## Windows 10 motion and materials

- Startup now tolerates Windows 10 systems that reject the tray Efficiency Mode request, preventing that optional optimization from blocking `WidgetManager` initialization and desktop organization.
- Resize, capsule, expand, and collapse operations reduce redundant UI-thread and window-position work while continuing to animate the real widget windows.
- Resize guidance is updated more efficiently and keeps the illuminated edge feedback.
- Windows 10 has a dedicated compatibility path for acrylic, solid, and fully transparent materials. Mica and system window corners are identified as Windows 11-only.
- Rapidly interrupted animations hand off to the latest operation more cleanly.

## Traditional Chinese

- Traditional Chinese (`zh-TW`) is available in DeskBox and the x64 and ARM64 installer definitions.
- Language persistence, update notes, weather, city search, lunar calendar content, Todo, Quick Capture, and desktop organization distinguish Simplified and Traditional Chinese.
- All 12 JSON language resources contain the same 2,350 keys with matching formatting placeholders.

## 中文说明

DeskBox 1.4.3 于 2026 年 8 月 19 日发布。

本次更新主要改善 Windows 10 上的格子交互，同时保留真实窗口参与尺寸调整、胶囊切换以及完整格子的展开和收起动画，并在应用与安装程序中加入繁體中文。

## Windows 10 动画与材质

- Windows 10 拒绝托盘效率模式请求时，启动过程会跳过这项可选优化，避免阻断 `WidgetManager` 初始化和桌面整理。
- 调整尺寸、胶囊切换、展开和收起继续驱动真实格子窗口，同时减少 UI 线程计算和重复窗口位置更新。
- 尺寸调整辅助提示改为更轻量的更新方式，并保留边缘发光反馈。
- Windows 10 使用独立的亚克力、纯色和全透明兼容路径。云母和系统窗口圆角会明确提示仅适用于 Windows 11。
- 连续快速操作时，新动画能更顺畅地接替未完成的旧动画。

## 繁體中文

- DeskBox 與 x64、ARM64 安裝程式定義新增繁體中文（`zh-TW`）。
- 語言儲存、更新說明、天氣、城市搜尋、農曆內容、待辦、隨記與桌面整理均能區分簡體和繁體中文。
- 12 份 JSON 語言資源均包含相同的 2,350 個鍵，格式化預留位置也保持一致。
