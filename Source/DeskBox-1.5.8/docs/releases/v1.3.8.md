# DeskBox 1.3.8

DeskBox 1.3.8 makes the core file-widget workflow easier to understand and more reliable. It adds six language options, clarifies how files and folders are handled, and resolves several clipboard and selection problems.

## Highlights

- **Six new language options:** Hindi, Spanish, French, Arabic, Bengali, and Russian are now available for the main file-widget, onboarding, weather, and update flows.
- **Clearer first file widget:** the first file widget opens on the right side of the screen, explains managed storage and folder mapping, and points to the system tray to create another widget.
- **Better file operations:** paste from the desktop into a widget, copy or cut multiple selected files to Explorer, and move files without leaving an incorrect cut appearance behind.
- **Consistent product language:** file widgets, folder mapping, automatic stacks, widget groups, tray creation, and Move to Recycle Bin now use one vocabulary across the app.
- **More reliable startup and desktop behavior:** startup remains tray-first, intentional launches remain interactive, removed file widgets are not recreated, and dynamic widgets stay on the desktop when using Win+D.
- **Complete uninstall when requested:** uninstall can keep application data for a later reinstall or permanently remove settings, widget layouts, notes, tasks, caches, logs, update files, and recovery snapshots. Files in the configured managed-storage location are never removed by the uninstaller.
- **Installer language fixes:** localized install, dependency, upgrade, and uninstall prompts now show paths and item counts correctly, and all six new installer languages carry into DeskBox on first launch.
- **Independent ARM64 updates:** ARM64 builds use their own installer URL, SHA-256, and size from the stable update manifest.

## Language coverage

The six new language packs prioritize the primary file-widget, onboarding, weather, and update experiences. A small number of less-used detailed settings still display in English while translation continues; this prevents unrelated Chinese text from appearing in another language.

The x64 and ARM64 installers offer the same eleven selectable interface languages as DeskBox. Their dependency download and uninstall prompts are localized too.

## Download and verification

The GitHub Release provides framework-dependent installers for both architectures:

- `DeskBox_Setup_1.3.8_x64.exe` for most Intel and AMD PCs.
- `DeskBox_Setup_1.3.8_arm64.exe` for native Windows on ARM PCs.
- A SHA-256 sidecar for each installer.

The installer reuses a compatible .NET 10 Runtime and Windows App Runtime 2.2 when they are already installed, and downloads only a missing matching dependency.

## 中文说明

DeskBox 1.3.8 让文件格子的主要流程更易理解、更稳定，并新增 6 种语言选项，重点优化文件处理、新手引导和更新体验。

- **新增 6 种语言**：印地语、西班牙语、法语、阿拉伯语、孟加拉语和俄语已覆盖文件格子、新手流程、天气和更新等主要体验。
- **首个文件格子更清楚**：默认从屏幕右侧打开，说明收纳存储与文件夹映射的区别，并提示可从系统托盘新建格子。
- **文件操作更可靠**：支持从桌面直接粘贴到格子；多个选中文件复制或剪切到资源管理器时保持完整选择；移动完成后会正确清理剪切样式。
- **产品术语统一**：文件格子、文件夹映射、自动叠放、格子组、托盘创建和移入回收站使用统一表述。
- **启动与桌面行为更稳定**：开机启动继续驻留托盘，主动打开保持交互式体验；用户删除的文件格子不会被自动补回；Win+D 后动态格子仍保留在桌面。
- **按需彻底卸载**：卸载时可选择保留应用数据以便重新安装，或永久删除设置、格子布局、随记、待办、缓存、日志、更新文件和恢复快照；卸载器不会删除配置的收纳路径内的真实文件。
- **安装器多语言修复**：安装、依赖下载、升级和卸载提示现在能正确显示路径和数量，新增的 6 种安装器语言也会在首次启动时传递给 DeskBox。
- **ARM64 更新独立校验**：ARM64 使用独立安装包地址、SHA-256 和大小。

### 多语言范围

新增语言优先覆盖主要体验；少量不常用的详细设置仍在持续翻译，暂时显示英文，以避免出现中文混杂。

x64 和 ARM64 安装器同样提供与 DeskBox 一致的 11 种可选界面语言，依赖下载和卸载提示也会随语言切换。

### 下载与校验

GitHub Release 提供以下框架依赖安装包及各自的 SHA-256 校验文件：

- `DeskBox_Setup_1.3.8_x64.exe`：适用于大多数 Intel 和 AMD 电脑。
- `DeskBox_Setup_1.3.8_arm64.exe`：适用于 Windows on ARM 电脑。

安装程序会复用已安装的兼容 .NET 10 Runtime 和 Windows App Runtime 2.2；仅在缺少对应依赖时下载安装。
