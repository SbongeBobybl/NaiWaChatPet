# DeskBox 1.5.6

DeskBox 1.5.6 is a big multiscreen, appearance, and layout release. Widgets now belong to the display they sit on, and every combination of connected displays remembers its own arrangement — unplug a screen and its widgets move over (or collapse into capsules) after a short grace period, plug it back in and everything returns to its exact spot, and first-seen combinations seed sensibly instead of piling onto the primary; Windows-side changes (primary switches, resolution and scale round-trips, sleep and lock re-enumerations, full-screen games, late docks) no longer shuffle widgets. Layouts reflow elastically when a display's resolution or scale changes — each widget keeps its size and anchor instead of being resized proportionally — so 1080p ↔ 4K switches and remote sessions land sensible arrangements instead of oversized widgets swimming in whitespace. A full backup restored onto another machine or account now adapts to it: the startup registration it recorded is re-registered here, and its account-local paths move to the current user, with the restore notice saying what was done. Widgets can dress up: per-widget icon swapping (emoji or image), per-widget background images with fit and dim controls, border styles, three global background modes including a panorama where each widget frames its own slice of the image by its position on the desktop, and a text-shadow toggle. A new Displays page pins widgets and groups to a display by hardware identity — surviving sleep, reconnects, and display renumbering — with an arrangement preview, one-click identify, pin-all, and a clearable default display for new widgets. Elevated launches explain themselves: running as administrator blocks drag and drop with Explorer, so DeskBox now notices, explains, and offers a one-click restart at normal privileges (autostart launches restart themselves and clear the RUNASADMIN compatibility flag). The settings window got an information-architecture pass (accordions, reordered pages, Windows-style slide transitions, whole-row entry cards, readable native notice bars), destructive actions ask before they act — dissolving a group confirms through a flyout, dangerous buttons wear a consistent style, and confirmations default to the safe choice — and the direct-edition uninstaller guards data when the Store edition may still be installed. It also adds a press-to-record hotkey editor, silent startup, a copy-first managed-storage migration, three new reveal effects plus Spring easing and staggered timing, a configurable auto-organize dwell, a weather icon-style picker with four bundled vector sets, drag-out modifier-key and result hints, notifications that deep-link to the settings page they concern, a rebuilt first-run walkthrough, and a run of feedback-driven fixes: Windows 10 drag-outs without Explorer's operation picker, tray double-click replay, a compact capsule stuck expanded, clipboard images from WeChat/QQ that standard decoding rejected, and an unexplained empty search state while Everything is not connected. Platform: Windows App Runtime 2.5.1, and the Windows 10 floor drops to build 19041 (version 2004).

Release date: 2026-10-02, extended through 2026-10-12 (content prepared from `main` at `1542fcd8` — the 1.5.6 code batch, PR #495 — plus the display-binding, multiscreen-behavior v2, elevation-launch-gate, WinAppSDK 2.5.1 / Windows-10-floor, settings-window reorganization, silent-startup, tray crossing-fade, uninstaller-guard, touch-pointer, and hotkey-recorder batches; further extended after `main` `c1acca9c` (PR #508, 1.5.6 final batches) with the UI-visual-line v3.1 batches on `feat/ui-visual-v31` through `7a32be54` (including the Windows-10 dark-theme InfoBar fix), and the 2026-10-11 pre-release file-safety audit fix round, all merged to `main` via PR #520 and PR #522 (`4f6c3088`); further extended on 2026-10-12 with the working-tree batches — elastic-layout reflow (topology-profile migration v2), restore machine-local recovery, notification deep-linking and reminder scenarios, dissolve confirmations with danger button styling, cloud-backup inline password validation, the onboarding walkthrough rebuild, and jump-list grouping; and extended again on the evening of 2026-10-12 with the file-stack settings reorganization (two-accordion layout, master-switch retirement with schema 13→14 migration), the music hide-empty-timeline option, the long-hide icon-pin memory fix, and two capsule fixes — which join this release (the tree is repackaged from this final state on 2026-10-12; final date to be set when publication is authorized).

## Highlights

- **Widgets belong to their display.** Dragging a widget to a screen makes that screen its home. Every combination of connected displays keeps its own arrangement; unplugging a display moves its widgets to a remaining screen after a short grace period (reflowed against the remaining display's reference frame, or collapsed into capsules if you set it so), and replugging returns every widget to its exact spot. A combination seen for the first time seeds from the most similar previous arrangement instead of dumping everything onto the primary.
- **Layouts reflow elastically across scales.** Topology profiles now record each widget's size and anchor against a per-display reference frame instead of raw pixels, so switching between 1080p and 4K, dropping into a remote session, or round-tripping a DPI change reflows the arrangement instead of proportionally resizing widgets into oversized tiles or whitespace gaps. Shrinking always compresses the gaps first, fixed-content widgets (weather, music, system, glance) cap their growth, and a hard minimum keeps every widget visible; existing profiles migrate once, in place.
- **Windows no longer shuffles your widgets.** Switching the primary display, changing resolution or scale, rearranging monitors, lock-screen and sleep re-enumerations, and full-screen games that temporarily change the resolution all leave widgets where they are. Startup waits out late-arriving dock and DisplayLink displays instead of crowding every widget onto the laptop screen and scattering them again.
- **Elevated launches explain themselves.** Elevated DeskBox cannot accept drags from Explorer — a Windows security boundary — so an elevated launch now shows a notice with a one-click "restart with normal privileges" button, or a plain explanation when the machine has no standard-user context to relaunch into (UAC off). Autostart launches restart themselves automatically, guarded against loops, and the compatibility flag that keeps relaunching DeskBox elevated is cleared along the way.
- **Record your own hotkeys.** The global and search hotkey cards gain a press-to-record editor: any Win / Ctrl / Alt / Shift combination, or a lone F1–F24 key, becomes the global hotkey (the search hotkey takes everything except Win-key chords), system-reserved chords like Win+V or Alt+Space record because the keys are intercepted for the dialog, chords owned by the other hotkey are rejected outright, risky combinations warn, the presets stay one click away, and the live hotkeys pause while you record.
- **Dress up your widgets.** Every widget can swap its icon for an emoji (categorized picker, recents, random roll) or a local image, set its own background with contain / fill fit and a dim slider, and pick a border style. Global widget backgrounds offer three modes — follow the material, one unified image, or a panorama where each widget frames its own slice of the image by its position on the desktop — and Appearance gains a text-shadow toggle.
- **Pin widgets to a display.** The new Displays page (Settings) shows an arrangement preview with per-screen widget lists, flashes a number on each screen to identify it, pins every widget to the current layout in one click, and sets a clearable default display for new widgets. Widgets and groups also bind from their context menu; bindings follow display hardware identity, so they survive sleep, reconnects, and Windows renumbering displays, and fall back gracefully while the bound display is offline.
- **A tidier Settings window.** Low-frequency settings fold into expandable accordions, pages are reordered to put fundamentals first, section changes slide in and out the way Windows' own Settings do, entry cards are clickable across the whole row even with inline controls, and notice cards render as readable native info bars with a proper severity tint.
- **Run quietly, migrate safely.** Silent startup keeps DeskBox hidden until the first tray click, hotkey, or activation. Moving files into managed storage is now copy-first: preview, per-phase progress (preparing / copying / verifying / committing), resumable retry, and dedicated errors — every file is hash-checked on both sides before the storage path switches, and the originals are never deleted; they stay untouched in the old location.
- **Motion and timing.** Three new reveal effects (Edge scale, Tilt, Wipe), a Spring easing option, and staggered per-widget timing; hiding widgets slides them fully out with a per-window fade as they cross the screen edge; desktop files wait a configurable dwell — real-time to 12 hours — before auto-organizing.
- **Pick a weather icon style.** Settings → Weather gains an icon-style combo with four bundled vector sets: Fluent (Microsoft Fluent Emoji Color, MIT — the Windows 11 emoji look and the new default), DeskBox hand-drawn line-art, Meteocons Flat, and Meteocons Line (MIT). Rendering goes through bundled SVG assets instead of the Segoe UI Emoji font, so Windows 10 and 11 show the same icons.
- **Windows 10 drag-outs without the operation picker.** Ordinary file drags out of a widget no longer surface Explorer's Copy / Move / Cancel chooser, a brief Shift/Ctrl hint shows at the top of the widget while dragging, a toast reports the operation that actually ran, and the "when dragging out of a widget" drop-down in settings lists its options again on Native AOT builds.
- **Tray icon calms down.** A second click inside the double-click window completes quietly instead of replaying the toggle queue and hiding widgets right after the reveal animation (feedback 237). The tray context flyout retries its assignment on early-logon sessions and falls back to the native menu instead of failing startup (feedback 343).
- **Capsule lease fix.** The widget foreground-color picker handoff is now released on every dismissal path — a compact capsule no longer stays expanded forever after the menu closed another way (issue 437).
- **Feedback honesty.** Submissions only start the cooldown when they succeed, and a stale server-side rate limit heals itself by rotating the anonymous client id instead of locking you out (issue 449).
- **Explained empty states.** Search tells you when an all-empty file list is because Everything — the file-name provider — is not connected (feedback 291); empty widgets get a help card spelling out the likely cause and fix.
- **Clipboard images that used to fail.** Quick Capture falls back to the raw PNG / CF_DIB payloads when the standard bitmap channel cannot decode the image, so captures from WeChat, QQ, and browsers land instead of reporting "empty or unsupported" (feedback 335).
- **Managed-storage guards.** Renaming a widget's managed folder retries briefly against transient handles (antivirus, indexer) and reports a clear message when a persistent lock — like an Explorer window inside the folder — remains (feedback 240). Choosing the desktop or a desktop subfolder as the storage root is rejected up front, and network / removable / system-drive roots warn before they are accepted.
- **Restores adapt to the machine.** A full backup restored onto a different machine or Windows account no longer carries the source machine's dead state with it: the startup entry the backup says is on gets re-registered here (a restored "off" stays off, and deliberate Windows-level disables are never overridden), and the account-local paths it stored — the managed storage root, the custom snapshot folder, and default-storage file widgets — move from the source account's profile to the current one, with the empty storage folder created so file widgets resolve immediately. The restore-complete notice reports what was adapted; the launch that applies a restore skips its scheduled snapshot (the pre-restore safety archive already covers that state) so the stale folder is never touched.
- **Destructive actions ask properly.** Dissolving a widget group from the group switcher confirms through a small flyout before acting instead of firing immediately; dangerous buttons across the settings window wear a consistent red style, restore-snapshot confirmations default to the safe button, and folder-delete confirmations show the parent path so you can tell same-named folders apart.
- **Notifications take you where you need to go.** An available update arrives as a native toast that opens the About page directly, maintenance and folder-mapping notices deep-link to the exact settings section they concern and can be dismissed individually, and todo reminders carry the proper reminder priority; saving cloud-backup credentials with an empty password explains itself inline instead of popping a dialog.
- **A rebuilt first-run walkthrough.** The onboarding scenes (taskbar, tray menu) were redrawn and page transitions rebuilt on system-managed animations that respect the "disable animations" setting; jump-list entries group under the system-localized Tasks section instead of a custom one.

### Also fixed (user-visible)

- Native AOT builds: the cloud-backup page's password box resolves correctly again — "Test connection" and "Save" no longer throw "Specified cast is not valid" (incident P1-1, rooted via DynamicDependency plus an AOT deep-smoke regression check).
- The music widget no longer throws on stale session reads when a player exits or churns mid-refresh — the recurring timeline exception noise in diagnostics is gone.
- Diagnostics exports keep HRESULT hex error codes readable instead of redacting them as secrets.
- The global hotkey and search hotkey cards explain that hotkeys cannot reach DeskBox while the focused window runs elevated — a Windows security limitation, not a DeskBox fault.
- Microsoft Store edition: backup restores no longer fail at the relaunch step — the restart now goes through the packaged-app restart agent instead of the direct-install-only updater helper.
- A cross-volume drag-in that finished copying no longer reports total failure when one source file is still held open by another program: the import completes with a warning that the leftover sources can be deleted manually, and sources that still exist keep showing in the widget they came from — the old failure card read as "nothing imported" and invited duplicate retries (feedback 236/316).
- The restore-complete notice only claims what actually happened: a path rebase that could not be persisted stays silent instead of announcing success, and the Store edition's pending startup-consent dialog no longer counts as "re-registered".
- Native AOT builds: the weather widget no longer shows an empty exclamation-mark overlay over perfectly loaded data — the first-load error overlay's four bindings were missing from the AOT binding manifest, so on retail builds the overlay rendered permanently visible with no title, body, or retry label (JIT Debug builds were unaffected). The manifest now covers the weather surface end to end, pinned by a new contract test that fails when a runtime binding is added without its AOT root.
- Native AOT builds: resize and move cursors work again — the protected-cursor lookup was trimmed out of retail compilation, so hovering a widget's resize borders, the search window's grips, or a compact capsule's move handle kept the plain arrow on retail while Debug showed the right cursor. The lookup is now rooted, and the cursors are cached per shape instead of recreated on every hover.
- Native AOT builds: the "transparency effects are off" material advisory works again — the system-switch read went through a name-based lookup that retail compilation trimmed away, silently treating transparency as always enabled and never surfacing the acrylic fallback warning. It is now a direct contract call within the Windows 10 19041 floor.
- The storage-migration dialog closes on Esc and places its primary action consistently; the feedback-submitted notice renders its border correctly in both themes.
- The file-stacking settings page is reorganized into two accordions — reveal mode first (its popover layout and visual-style options are configurable only for popover reveal and freeze for inline reveal), then automatic stacking with its grouping rules and custom-format editor. The retired master switch folds into automatic stacking (a lingering master-off profile migrates to auto-off with manual stacks back); the file-widgets overview row shows the reveal mode inline, and the desktop storage-entry card moved to the bottom of the page below the original-desktop-context-menu card.
- Music widgets can hide the progress bar and times when the player provides no progress info (Settings → Music, on by default), instead of showing a blank placeholder.
- Hidden or docked widgets release the icons outside the rendering window, so they no longer pin bitmaps the icon cache already evicted — the long-hide memory growth path is closed.
- A compact capsule no longer collapses while a native context menu is open, and no longer snaps to the panel's bottom edge when collapsed after resizing the widget in expanded state.

### File-safety hardening (pre-release audit round)

A three-round, multi-agent file-safety audit (drag-out, drag-in, auto-organize, migration/backup, deletion/lifecycle, historical regressions; adversarial verification plus a blind-spot sweep) ran against this tree before release. It confirmed the core safety architecture and found zero P0 paths; every reachable data-loss or promise-breaking path it did find is fixed in this build:

- A full backup restore can no longer apply without your answer: the pending-restore marker is confirmed only after the dialog's "restore" button, and a crash, exit, or hidden settings window while the dialog is open discards the restore at the next launch instead of swapping the data directory.
- Deleting search results (single, multi-select, or Ctrl+A + Delete) goes through the Windows confirmation dialog; on volumes without a Recycle Bin the retired self-drawn dialog could silently degrade to a permanent delete that contradicted its own "move to Recycle Bin" promise.
- Deleting a widget folder stored on a network drive no longer bypasses the Recycle Bin: headless deletions on network volumes are refused, and the close/settings flows route through the interactive Shell confirmation.
- Removing an attachment from a todo or Quick Capture item only ever deletes copies that provably live inside the managed attachment store, and does so through the Recycle Bin — a stale "managed copy" flag can no longer authorize deleting a user's original file.
- Closing a widget whose "move files back to the desktop" cannot complete keeps the widget and explains what happened, instead of silently leaving a half-moved state.
- Files dragged out of a widget and dropped back shortly afterwards are no longer silently ignored when a previous drag's completion event was lost.

## Remaining release-boundary checks

- Full-restore cross-account on real hardware: back up on one Windows account, restore on another (or another machine) — the startup task re-registers, the managed storage root moves to the current account's profile with the folder created, and the restore notice reports both adaptations.
- Elastic reflow on real hardware: a 1080p ↔ 4K switch, a remote-session round-trip, and the one-time topology-profile migration for a user upgrading from 1.5.5.
- Pushing, the GitHub release and the Partner Center submission await explicit approval.
- Multiscreen v2 on real hardware (full scenario table in `docs/requirements/multiscreen-behavior-spec-真机验证清单.md`): primary-display switch, resolution round-trip, unplug → grace → move → replug → exact restore, first-seen combination seeding, KVM / DP-sleep dropouts, late dock arrival at startup, and the Q1–Q4 decisions from the implementation report.
- Elevated-launch gate on real hardware: run the installed DeskBox.exe as administrator → notice with the one-click unelevated restart, drag-and-drop working after the restart; a UAC-off machine → explanation-only notice; an autostart entry forced elevated → silent self-relaunch unelevated.
- Real-machine spot checks on the packaged build: Windows 10 drag-out (no operation picker, move/copy result hint correctness — the six-item dragfix2 checklist), the weather icon-style picker across all four sets and three layouts plus the compact capsule, the cloud-backup password box on the AOT retail build, and the tray double-click behavior.
- Windows 10 2004 (build 19041) installation on the lowered floor; clean-machine install with the network disconnected — the bundled private WinAppRuntime 2.5.1 carries everything, no runtime is downloaded and no system-wide runtime gets installed.
- Display binding on real hardware: sleep/lock → wake with displays renumbered, unplug the bound display and replug it, mixed-DPI dual-screen pin-all, the identify overlay's number size and fade, and the Win10 frame-pacing behavior of the tray crossing-fade (recorded frame-by-frame on a dual-screen Windows 10 machine before sign-off).
- The settings-window reorg pass: accordions expand with disabled (not hidden) sub-cards outside custom presets, notice bars readable in both themes, search still routes into accordion sections.
- Direct-edition uninstaller: store edition installed → data preserved with the new accurate message; PowerShell probe broken on a stripped-down Windows 10 → fail-closed path.

### 主要更新

- **格子归属显示器。** 把格子拖到哪块屏，那块屏就是它的归属；每种显示器组合各自记住摆放。拔屏后经短暂宽限移到剩余屏（按剩余屏参考系弹性重排，或收起为胶囊），接回时逐格精确归位；首次出现的组合按最相似既往布局播种。
- **布局随缩放弹性重排。** 拓扑档案改为按"每屏参考系"记录每个格子的尺寸与锚点，而不再是原始像素——1080p 与 4K 互切、进入远程会话、DPI 往返都按弹性规则重排，不再把格子按比例缩成过大或留出大片空白。缩小时优先压缩间距，天气/音乐/系统/一览等固定内容格子有放大上限，硬性最小尺寸保证每个格子始终可见；存量档案一次性就地迁移。
- **Windows 不再打乱你的格子。** 切换主显示器、改分辨率缩放、重排显示器、锁屏睡眠重枚举、全屏游戏临时改分辨率——格子都不动；启动等待晚到的扩展坞/DisplayLink 屏，不再先挤到笔记本再散开。
- **管理员运行有说法了。** 提权启动弹窗说明拖拽受限（Windows 安全边界），一键以普通权限重启；UAC 关闭等无法降权的机器给出解释；自启提权实例自动重启（带循环断路器），并清除反复提权的兼容性标记。
- **快捷键可以自己录了。** 全局与搜索快捷键卡片新增按键录制编辑器：Win/Ctrl/Alt/Shift 任意组合或单独的 F1–F24 即可设为全局快捷键（搜索快捷键除 Win 键组合外均可），Win+V、Alt+Space 等系统预留组合因录制期按键被拦截也能录入；与另一个快捷键冲突的组合直接拒绝、高风险组合先行提醒，预设一键可选，录制期间现有热键暂停触发。
- **装扮你的格子。** 任意格子可换表情图标（分类选择器、最近使用、随机）或本地图片，设置自己的背景图（包含/填充契合度+明暗调节）与边框样式。全局格子背景三模式——跟随材质、统一图片、按各格桌面位置取景的全景图片；外观新增文字阴影开关。
- **把格子钉在指定显示器上。** 新的「显示器」设置页带排列预览与逐屏格子清单，一键识别（各屏闪现编号）、一键固定当前布局、可清除的新格子默认屏。格子与格子组也可从右键菜单绑定；绑定跟随显示器硬件身份，睡眠、重插、Windows 重排编号都不受影响，绑定屏不在线时自动回落。
- **更清爽的设置窗口。** 低频设置收进风琴卡，页面按基础优先重排，分区切换带 Windows 设置式左右滑入转场，入口卡整行可点（含内联控件），提示条改用带提示色、清晰可读的原生信息条。
- **安静启动，安全迁移。** 静默启动让 DeskBox 一直隐藏到第一次托盘点击、热键或激活。文件迁入受管存储改为先复制：预览、分阶段进度（准备/复制/校验/提交）、可恢复重试与专属错误——每个文件都经双侧哈希校验通过后才会切换收纳路径；源文件全程保留在原位置，软件绝不自动删除。
- **动效与时机。** 三个新显示效果（边缘缩放、倾斜、擦除）、弹簧缓动与逐格错峰时序；隐藏格子完整滑出并在跨屏边缘逐窗渐隐；桌面文件可配置停留多久后才被自动整理（实时到 12 小时）。
- **天气图标风格选择。** 设置 → 天气新增图标风格下拉：Fluent（微软 Fluent Emoji 彩色版，MIT，Windows 11 观感，新默认）、DeskBox 手绘简笔、Meteocons 扁平、Meteocons 线框（MIT）。渲染改走内置 SVG 资产而非 Segoe UI Emoji 字体，双系统显示一致。
- **Windows 10 拖出不再弹选择框。** 普通左键拖出不再触发 Explorer 的"复制 / 移动 / 取消"操作选择器，拖出时格子顶部短暂显示 Shift/Ctrl 修饰键提示，松手后弹出实际执行操作的结果提示；设置里"拖出格子时"下拉在 Native AOT 版恢复显示选项。
- **托盘图标安静下来。** 双击窗口内的第二次点击静默完成，不再重放切换队列把刚展开的格子藏起来（反馈 237）。早期登录会话中托盘右键菜单赋值失败时按节奏重试，并回退原生菜单而不再启动失败（反馈 343）。
- **胶囊租约修复。** 格子前景色取色器的交接在所有关闭路径上都会释放——紧凑胶囊不再永久保持展开（issue 437）。
- **反馈诚实。** 提交只有成功后才计入冷却；服务端残留的限流状态通过轮换匿名客户端 ID 自愈，不再把你永久锁在门外（issue 449）。
- **有解释的空状态。** 文件名搜索提供方 Everything 未连接时，全空的文件列表会给出说明（反馈 291）；空格子带帮助卡，写明可能原因与处理办法。
- **以前接不住的剪贴板图片。** 标准位图通道解码失败时，随记回退读取原始 PNG / CF_DIB 数据——微信、QQ、浏览器的截图现在能正常进来（反馈 335）。
- **受管存储守卫。** 重命名格子受管文件夹会对瞬时占用（杀毒、索引器）短暂重试，遇到长驻占用（如 Explorer 窗口停在文件夹内）给出明确提示（反馈 240）。把桌面或其子文件夹选作收纳根会被提前拒绝；网络、可移动磁盘、系统盘根目录在接受前会给出预警。
- **还原适配本机。** 整包备份还原到另一台机器或另一个 Windows 账户，不再带着源机器的失效状态：备份里记录为"开"的开机自启在本机重新注册（还原为"关"则保持关，Windows 层面的主动禁用永不覆盖），它存的账户本地路径——收纳存储根、自定义快照目录、跟随默认根的文件格子——从源账户迁移到当前用户，并创建空的存储根目录让文件格子立即可解析。还原完成通知会说明做了哪些适配；应用还原的那次启动会跳过计划快照（pre-restore 安全档案已覆盖该状态），旧目录不再被触碰。
- **危险操作先确认。** 从格子组切换器解散组改为先经小型飞出层确认再执行；设置窗内危险按钮统一红色样式，还原快照确认框默认落在安全按钮，文件夹删除确认显示父目录路径以便区分同名文件夹。
- **通知直达要去的地方。** 有可用更新时以原生 toast 通知并直接打开"关于"页；维护与文件夹映射通知深链到对应的设置分区、可逐条关闭；待办提醒带正确的提醒优先级；云备份凭据空密码改为就地内联提示而非弹窗。
- **重绘的首次运行引导。** 引导场景（任务栏、托盘菜单）重新绘制，换页动画改用系统托管动画并尊重"关闭动画"设置；跳转列表条目归入系统本地化的"任务"分组。
- **商店版还原修复。** 备份还原不再在重启环节失败——重启改走打包应用重启代理，不再依赖直装版专属的更新器进程（1.5.5 商店版即带此病）。
- **跨盘拖入的诚实收尾。** 复制完成但个别源文件仍被其他程序占用时，导入不再整体判失败：按「已完成」收尾并警告说明未删除的源文件可待程序关闭后手动清理；仍存在于原位置的文件继续留在来源格子中。旧的失败卡片曾让用户以为什么都没导入而重复拖入（反馈 236/316）。
- **还原通知只说真话。** 路径迁移未能持久化时通知保持沉默而非宣称成功；商店版的启动同意弹窗等待中不再被计为"已重新注册"。
- **Native AOT 版：天气格子不再在已加载的数据上盖一个空的感叹号遮罩**——首次加载失败遮罩的四个绑定漏进了 AOT 绑定清单之外，零售构建上遮罩以"无标题、无正文、无重试文字"的形态永久可见（JIT Debug 构建不受影响）。清单现已覆盖天气绑定面，并由新增契约测试守护：运行时绑定新增而未加 AOT 根时直接红。
- **Native AOT 版：缩放与移动光标恢复工作**——受保护光标的反射查找被零售编译裁掉，零售包上悬停格子缩放边、搜索窗手柄或紧凑胶囊移动手柄时一直显示普通箭头（Debug 正常）。查找现已保根，光标也改为按形状缓存而不再每次悬停重建。
- **Native AOT 版：透明效果关闭的材质提示恢复工作**——系统开关读取走的按名查找被零售编译裁掉，透明被静默当作"始终开启"、亚克力回退警告从不出现。现改为 19041 地板契约内的直接调用。
- 收纳迁移对话框支持 Esc 关闭、主操作按钮位置统一；反馈提交通知的边框在双主题下正确渲染。
- **文件叠放页重组。** 设置拆为两个风琴——展开方式在前（弹窗布局与视觉样式仅"弹出式展开"可配置，"当前布局内展开"时冻结），自动叠放及其归组规则、自定义格式编辑器在后。退役的总开关折叠进自动叠放（残留的"总开关关"配置迁移为"自动叠放关+手动叠放恢复"，settings schema 13→14）；文件格子总览行内联展开方式下拉，"桌面上的收纳文件入口"卡移到页面最底部（桌面原版右键菜单卡下方）。
- 音乐格子可在播放器不提供进度信息时隐藏进度条与时间（设置 → 音乐，默认开启），不再显示空白占位。
- 长时间隐藏或停靠后，格子释放渲染窗口外的图标，不再钉住图标缓存已逐出的位图——长隐藏内存增长路径关闭。
- 胶囊两修：系统右键菜单打开期间不再误收起；展开态调整高度后收起不再跳到面板底边。
- **文件安全加固（发版前审计轮）。** 发版前对该代码树做了三轮、多 Agent 的文件安全审计（拖出/拖入/自动整理/迁移备份/删除与生命周期/历史回归，外加对抗复核与盲区补扫）：核心安全架构得到独立重验、未发现 P0 路径，审计发现的全部可达数据丢失或"承诺与行为不符"路径均已在本版修复——全量还原必须经确认才会应用（确认框未答复时崩溃/退出，下次启动直接丢弃待定还原）；删除搜索结果（单项/多选/Ctrl+A）改走 Windows 系统确认，无回收站的卷上不再静默永久删除；网络驱动器上的格子文件夹删除不再绕过回收站（后台删除被拒绝或改经系统交互确认）；待办/随记附件移除只删确凿位于托管附件目录内的副本、且走回收站（错标的"托管副本"标志再也无法授权删除用户原始文件）；关闭格子时移回桌面未完成则格子保留并明确提示；拖出后短时间拖回的文件不再被静默忽略。
